While ATR is calculated as Average of True Range.
Average Relativ True Range is calculated as Average of Relativ True Range.
First we calculate min,max of True Range
Relativ True Range is calculated as (True Range -min)/(max/min)
Simple version
Relativ True Range is calculated as True Range /max
