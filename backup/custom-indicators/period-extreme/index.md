## Period Extreme

**Apprentice** · Wed Nov 30, 2011 5:33 am

![Period Extreme.png](images/19127/Period%20Extreme.png)



Buy
Signals and/or Trade are given when the value of the current candle exceeds the high of the previous one
Sell
Signals and/or Trade are given when the value of the current candle drops below the low of the previous one

The indicator is customizable, you can set some other periods.
Defalt value is 0.
0 = Higher / Lower then previous Candle extreme.
1 = Higher / Lower then Max / Min of Two previous Candle extreme.
....
And so on.
