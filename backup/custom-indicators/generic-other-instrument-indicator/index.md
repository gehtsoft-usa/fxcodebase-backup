## Generic Other Instrument Indicator

**Apprentice** · Mon Mar 12, 2012 6:27 am

![Generic Other Instrument Indicator.png](images/27924/Generic%20Other%20Instrument%20Indicator.png)



This implementation offers the possibility of retrieving indicators for other currencies.
There are certain limitations.
Using moving averages and other indicators, which are based on price,
is not always advisable.

**Oscillators, whose score is ralativan, comparable with other currency pairs,
do not have this problem.**
If you use 0 (zero) as Data Stream Number, all data streams, will be presented.

**This indicator will not work for indicators that do not give OutputStream, have a label output. As Fractal, MTF and similar.**

The indicator was revised and updated
