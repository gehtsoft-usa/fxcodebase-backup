Session & Swing Levels

This indicator plots key price levels directly on the chart. It includes today’s high, previous daily highs and lows, swing highs and lows, all-time high/low, and both previous and post session highs/lows. Vertical markers show session start and end times.
All levels are extended logically into the next trading day for practical use.

The tool provides a clean visual map of intraday and historical levels to support trading decisions.
