## Bollinger Bands Ratio

**Apprentice** · Tue Feb 09, 2016 6:37 am

![EURUSD H1 (02-09-2016 1203).png](images/104734/EURUSD%20H1%20%2802-09-2016%201203%29.png)



**"(Over+Under)/Total"**
Count if Price is above Top Line
or
Price below Bottom Line
VS LookBack period

**Over/Total & Under/Total"**
Count if Price is above Top Line VS LookBack period
Count if Price is below Bottom Line VS LookBack period

**"Over/Total & Under/Total Central Line"**
Count if Price is above Central Line VS LookBack period
Count if Price is below Central Line VS LookBack period
