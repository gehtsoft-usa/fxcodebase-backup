## RSI Rainbow Chart

**Apprentice** · Fri Aug 24, 2012 1:54 am

![Rainbow Charts Template.png](images/39151/Rainbow%20Charts%20Template.png)



This is a completely new way of data presentation.
Shows the value of the indicator for all periods.
This is an experimental indicator, further improvements are possible.

This indicator is not about accuracy, rather presentation.

For this purpose it use 3D averaging algorithm.
Every data point is an average of 9 points.
Current and Lines above and below, Current and periods above and below.
