## Last OBV Values (with Reset Options)

**Apprentice** · Fri Oct 03, 2025 2:48 pm

![USDJPY H8 (10-03-2025 2144).png](images/160749/USDJPY%20H8%20%2810-03-2025%202144%29.png)



This indicator prints only the latest OBV values directly on the chart, showing four variants: no reset, reset at start of day, reset at session open, and reset at session close.
Instead of plotting a full line, it provides a clean snapshot of where each OBV stands right now.

This can be useful for traders interested in short-term OBV behavior, for example spotting how volume flows shift within daily or session boundaries, and using it as a quick filter or confirmation for intraday signals.

 [Last OBV Values.lua](files/160749/Last%20OBV%20Values.lua)

## Last OBV – Session Strength Dashboard

**Apprentice** · Sat Oct 04, 2025 9:51 am

![TSLA.ext H1 (10-04-2025 1635).png](images/160751/TSLA.ext%20H1%20%2810-04-2025%201635%29.png)



his indicator splits daily OBV deltas into separate buckets: Trading (Regular hours), Extended (pre- & post-market), Off-hours, and optional Standard OBV (full day).
It compares Today vs Yesterday, showing average (per-bar) values by default, with an option to also display sums.
This makes it easy to see how OBV strength shifts between sessions and how today’s activity differs from the previous day.

 [Last OBV – Session Strength Dashboard.lua](files/160751/Last%20OBV%20Session%20Strength%20Dashboard.lua)
