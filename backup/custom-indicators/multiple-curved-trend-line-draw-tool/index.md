Based om Curved Trend line Progression Tool
[viewtopic.php?f=17&t=66833](https://fxcodebase.com/code/viewtopic.php?f=17&t=66833)
It offers simplified line addition, it is able to draw up to 5 lines.
Channel functionality is not available in this version.

 [Multiple Curved Trend Line Helper Tool.bin](files/129538/Multiple%20Curved%20Trend%20Line%20Helper%20Tool.bin)

Use the Multiple Curved Trend Line Helper Tool to define the lines.

 [Multiple Curved Trend Line Draw Tool.bin](files/129538/Multiple%20Curved%20Trend%20Line%20Draw%20Tool.bin)

Multiple Curved Trend Line Draw Tool will only draw all lines defined by the Multiple Curved Trend Line Helper Tool.
