Hello sir,
Is there a possibility to have a linear regression cross over indicator?
the used indicator is the regression line
Entry point is the crossover of the lighter (for example regression line (20)) to the heavier (regression line (50)) as shown in the attached chart
If the crossover is up we go long and if down we go short
Stop loss or exit will be a red candle closing below the regression line (50) in case of long and green candle closing above regression line (50) in case of short
That can be applicable to different pairs on different time frames with different settings of the regression line
