TS buildin / William %R formula is.
%R = (Highest High - Close)/(Highest High - Lowest Low) * -100
While TS buildin version require bar source.
U can use this version for use with tick sources.
%R = ( Source Highest - Source)/(Source Highest - Source Lowest) * -100
