## Normalized HL range

**Alexander.Gettinger** · Mon Dec 19, 2011 8:55 pm

The indicator shows the size of each candle and the average value.

Formulas:
NormHL[i]=High[i]-Low[i], if [Normalize] is false and
NormHL[i]=(High[i]-Low[i])/Abs(Time(High)-Time(Low)).
