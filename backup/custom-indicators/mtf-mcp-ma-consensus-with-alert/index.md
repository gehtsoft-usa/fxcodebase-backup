## MTF MCP MA Consensus With Alert

**Apprentice** · Sun Oct 05, 2014 7:27 am

![MTF MCP MA Consensus With Alert.png](images/96373/MTF%20MCP%20MA%20Consensus%20With%20Alert.png)



Indicator will show the moving average slope for all selected time frame.

If Update Type is set to Live mode.
Alert Audio / Email / Popup will be given Instantaneously, if a change in the consensus of all the selected time frames occur.
If Update Type is set to the end of turn, Alert Audio / Email / Popup will be given at the start of new candle, if a change in the consensus of all the selected time frames occur.
