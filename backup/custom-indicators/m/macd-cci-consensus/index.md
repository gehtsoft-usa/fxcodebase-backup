## MACD CCI Consensus

**Apprentice** · Wed Mar 06, 2013 2:36 pm

![MACD CCI Consensus.png](images/55881/MACD%20CCI%20Consensus.png)



**CCI Filter**
Up
CCI > 0
Down
CCI < 0

**MACD Filter**
Up
Value of MACD Component > Prev. Period Value of MACD Component
Down
Value of MACD Component < Prev. Period Value of MACD Component

**Consensus**
Up
CCI = Up
MACD = Up
Down
CCI = Down
MACD = Down

Neutral
If MACD and CCI indications are contradictory.

MACD Component < Prev. Period MACD Component
