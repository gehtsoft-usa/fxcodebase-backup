**MTF MCP Directional Move View** simplifies multi-timeframe analysis by allowing traders to quickly identify directional trends across selected instruments and timeframes.

For example, if **D1** shows an uptrend while **H1** shows a downtrend, the indicator highlights this directional mismatch—helping traders anticipate potential pullbacks or continuation setups.

**2TF MCP Directional Move View** is a lightweight version of the full MTF indicator. It focuses on **two user-selected timeframes** per instrument, making it ideal for fast visual analysis.

Unlike the full MTF version (which compares up to 13 timeframes), this version simplifies the view and adds intuitive **Same / Opposite direction filtering**.

For example, if H1 shows an uptrend and D1 a downtrend, the Opposite filter will highlight that divergence. If both show the same trend, the Same filter confirms alignment.
