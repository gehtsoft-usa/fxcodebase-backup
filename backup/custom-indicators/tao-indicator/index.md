Today is the last working day before lunar new year in Taiwan. We always gave lucky money in this season for Chinese traditional. I would like to share these lucrative tools including TAO,TDL,TDO as the new year present. Hope these would help you to make profit consistently.

The TAO indicator is applying to Trading Station II and TimeFrame only D1 or H4.
Technical Analysis Office simple tool for swing/options trader
The first parameter is "N: Look back" which defines the look back periods of base moving average, default 0 means by automatic setting.
The second parameter is "L: WeekRange lookback" which defines the look back periods for calculating weekly resistance.
The parameter "ShowIC" set to display range cloud for Iron Condor.
The parameter "ShowCS" set to display credit level for Credit Spread.
The parameter "ShowSN" set to display direction for Synthetic.
The parameter "ShowHV" set to display one sigma for Weekly Resistance.
The parameter "ShowCL" set to display projection for Weekly Calendar.
