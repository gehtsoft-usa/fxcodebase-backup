## Tail / Body Ratio

**Apprentice** · Wed Aug 29, 2012 11:05 am

![Tai  Body Ratio.png](images/39360/Tai%20Body%20Ratio.png)



This indicator will give a signal in the two cases.
1) Candlestick wick / tail is greater than candle body.
(Body* Multiplier) < Tail
2) Candlestick wick / tail is greater than the rest of the candle.
( (Body+ Opposite Tail) * Multiplier) < Tail
Which algorithm will be used is user choose.

 [TB Ratio.lua](files/39360/TB%20Ratio.lua)

 [TB Ratio with Alert.lua](files/39360/TB%20Ratio%20with%20Alert.lua)

This indicator provides Audio / Email Alerts if An arrow appears.
