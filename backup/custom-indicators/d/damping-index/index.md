![Damping index.png](images/56911/Damping%20index.png)



DI = (MAofHigh-MAofLow)/(MAofHighNPeriodAgo]-MAofLowNPeriodAgo)
Any value less than 1 is a strong indication that valid damping behavior has been detected.
