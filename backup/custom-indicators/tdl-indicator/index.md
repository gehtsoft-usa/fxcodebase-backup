## TDL indicator

**richardtao** · Tue Feb 09, 2021 1:54 am

The TDL indicator is applying to Trading Station II.
Technical Analysis Office simple tool for momentum trader.
This indicator is including five subset of line.
ACF is base on the sine swing. The parameter "L:Level" defines the swing multiplier of atr. The parameter "CK:check " defines the reverse sensitivity by atr.
ACS is based on the break of the band. The adjusted parameters were set by default.
ATL is simple trend line compare with the mirror reverted line.
RGS is liner regression with look back base.
SNA is recursive moving average compare with simple moving average. The parameter "L:Level" defines the first line reverse sensitivity by atr. The parameter "CK:check " defines the second line reverse sensitivity by atr.
