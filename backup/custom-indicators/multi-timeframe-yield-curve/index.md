**Multi-Timeframe Yield Curve**

Displays a normalized yield curve derived from multiple selected timeframes. Each selected timeframe is scaled and plotted as a comparative oscillator, enabling insight into the shape and dynamics of the multi-timeframe price structure.

Features:
• Supports 13 standard timeframes (m1 to M1)
• Custom scaling via time-based ratio normalization
• Optional absolute value transformation

Useful for identifying flattening/inversion patterns or divergences in multi-timeframe analysis.
