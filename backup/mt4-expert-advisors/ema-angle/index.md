Original indicator: [viewtopic.php?f=17&t=1294&p=28589](https://fxcodebase.com/code/viewtopic.php?f=17&t=1294&p=28589)

Formula:
Angle[i]=(EMA[i]-EMA[i-Shift])/pipSize.
If Angle>=Treshold - UP,
if Angle<=-Trreshold - DN.
