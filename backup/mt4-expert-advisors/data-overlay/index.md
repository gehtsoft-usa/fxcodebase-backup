Description:

This simple indicator displays the following information:

"Close/Low", "Close/Low(-1)", "High/Close(-1), "High/Close(-1)" and "MVA( PERIOD")/Close

For these Periods: 5,10, 20, 30, 60, 120, 250.

The data is displayed in Pips.
