## Family of screenshot indicators

**Alexander.Gettinger** · Tue May 01, 2012 5:51 pm

1. The indicator saves a screenshots at a specified time each day.
Files are stored in [MT4 directory\experts\files\] folder.

Download:

 [TimeScreenShot.mq4](files/31891/TimeScreenShot.mq4)

2. The indicator saves a screenshots with the specified time interval, for example, each two minutes.
Files are stored in [MT4 directory\experts\files\] folder.

Download:

 [TimeScreenShot2.mq4](files/31891/TimeScreenShot2.mq4)

3. The indicator saves a screenshots after a change (create\modify\close\delete) orders.
Files are stored in [MT4 directory\experts\files\] folder.

Download:

 [ScreenShot_Orders.mq4](files/31891/ScreenShot_Orders.mq4)
