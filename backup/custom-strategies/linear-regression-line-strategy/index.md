## Linear Regression Line Strategy

**Apprentice** · Mon Sep 24, 2012 1:31 pm

![Linear Regression Line Strategy.png](images/40832/Linear%20Regression%20Line%20Strategy.png)



Long
Short Period LRL CrossOver Long Period LRL
Short
Short Period LRL CrossUnder Long Period LRL

Exit Long
Price CrossUnder Long Period LRL
Exit Short
Price CrossOver Long Period LRL
