Enter Long if:
R3 is Green
R1 is Green AND R1 > R3
R2 is Green AND R2 >R3
Note: for Long R1 does not have to be > R2
Exit Long if R1 is Red AND if R2 is Red AND R1<R3

Vice Versa for Short
