## Cowabunga strategy

**Apprentice** · Sun Oct 14, 2012 6:06 am

![Cowabunga strategy.png](images/42013/Cowabunga%20strategy.png)



Long: ( m15 )
- EMA(5) must cross the EMA(5).
- RSI > 50
- Stoch needs to be heading upwards, but cannot be in the overbought limits.
- MACD has to be heading upwards, but has to be in the negative.

Short ( m15 )
- EMA(5) must cross the m15 EMA(10).
- RSI < 50
- Stoch must be going down and not in the oversold area.
- MACD must be going down but has to be in the positive.

All indications, they must be in the direction of trend, set by H4 EMA (10)

Exit Stop
20 pips

Profit Target Exit
30 pips
