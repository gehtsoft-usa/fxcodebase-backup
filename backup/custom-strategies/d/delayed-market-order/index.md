## Delayed Market Order

**Apprentice** · Wed Sep 07, 2016 6:21 am

[Delayed Market Order.lua](files/108002/Delayed%20Market%20Order.lua)

Trade will be opened at a set time.
If "Use Optional Exit " is used any previous positions will be closed.

If "Custom Identifier" filter is used, only positions with the same "Custom Identifier" will be closed
If "Currency Pair" filter is used, only positions in selected Currency Pair will be closed
If "All" filter is used, all positions will be closed.

The Strategy was revised and updated on January 18, 2019.
