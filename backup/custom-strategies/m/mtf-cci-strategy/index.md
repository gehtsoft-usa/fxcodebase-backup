## MTF CCI Strategy

**Apprentice** · Wed Nov 16, 2011 7:04 am

This is a highly adaptive strategy, which gives you the opportunity to test several different settings.
 Gives Long / Short Signals / Trades is a defined number of CCI is Growing / Falling. (Open Level)
You can also define a number of contraindications after which the trade is closed. (Close Level)

The set parameters are five for Open Level and three for Close Level.
If you use five for both, Trades are open only if all five time frames have the same indication.

 [MTF CCI Strategy.lua](files/17973/MTF%20CCI%20Strategy.lua)

The Strategy was revised and updated on November 21, 2018.
