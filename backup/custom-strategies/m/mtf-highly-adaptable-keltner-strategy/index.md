This strategy allows you to select the desired action for each cross of any Keltner line.
Selected, primary Trade Time Frame will trigger action by line cross.
Secondary confirmation Time Frame should be in the same state.

1) Example
1st TF Cross Over
2nd TF Price> Line

2) Example

1st TF Under cross
2nd TF Price <Line
