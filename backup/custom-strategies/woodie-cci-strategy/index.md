![MTF Woodies Strategy.png](images/42298/MTF%20Woodies%20Strategy.png)



This is a highly-adaptable MTF version of this strategy.
Enables you to try different setups.

Signals as generated.

Long
Woodies CCI / Buy Level Crossover
Short
Woodies CCI / Sell Level Crossunder

Or/ And Higer Time Frame Color confirmation can be used to confirm the signal.

Exit
Exit Long
Woodies CCI / Sell Level CrossUnder
Exit Short
Woodies CCI / Buy Level CrossOver

Or/ And Higer TIme Frame Color contraindication.

Optional Exit.
Single Time Frame (Any Selected)
If all on any selected time frame give contraindication.
Cumulative
If the number of contraindications is higher than Exit Limit strategy will close the Trade.

 [MTF Woodies Strategy.lua](files/42298/MTF%20Woodies%20Strategy.lua)

You need to have the latest version of Woodies CCI Indicator.
[viewtopic.php?f=17&t=8964](https://fxcodebase.com/code/viewtopic.php?f=17&t=8964)
Re-download, if you have old version.
