## MTF New Trend Indicator Strategy

![MTF New Trend Indicator Strategy.png](images/42794/MTF%20New%20Trend%20Indicator%20Strategy.png)



This is a highly adaptable strategy.
Trade Signal is Given if all selected time frame give Buy or Sell Signal.
Exit signal is given if all selected time frame give contraindication,
Additionally Exit Signal is Given if a certain number of time frames give contraindication.
