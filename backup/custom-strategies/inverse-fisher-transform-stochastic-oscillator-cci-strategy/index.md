## Inverse Fisher Transform Stochastic Oscillator/CCI Strategy

**Apprentice** · Tue Nov 20, 2012 9:05 am

![IFTSO  CCI Strategy.png](images/45180/IFTSO%20CCI%20Strategy.png)



Open Long
IFTSO / Buy Level CrossOver
ansd
CCI > Buy Level(optinal)

Open Short
IFTSO / Sell Level CrossUnder
and
CCI < Sell Level (optinal)

Exit (optinal)
Exit Long (optinal)
CCI /Sell Level CrossUnder(optinal)
IFTSO /Sell Level CrossUnder(optinal)

Exit Short (optinal)
CCI /Buy Level CrossOver(optinal)
IFTSO / Buy Level CrossOver(optinal)

 [IFTSO CCI Strategy.lua](files/45180/IFTSO%20CCI%20Strategy.lua)

For this strategy you have to install Inverse Fisher Transform Stochastic Oscillator.
