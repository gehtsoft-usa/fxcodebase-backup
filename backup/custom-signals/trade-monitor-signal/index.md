## Trade Monitor Signal

**Victor.Tereschenko** · Sat Jul 04, 2015 12:39 am

Signal shows an alert when:
1. An entry order is placed
2. An order is opened
3. An order is closed (partially or fully)
4. An order limit, stop, trailing stop, is set.
5. Monitors all pairs.
