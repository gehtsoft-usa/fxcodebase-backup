This is a simple VTDMI Signal.
You can turn on additional checks.
To check if DIP or DIM Exceed the specified level.

There are two verification algorithm.

Simple.
On DIP DIM Cross we check if DIP or DIM Exceed the specified level.
If Nor No signal is Given.

Advanced
At any time when both signals are positive signal are given.
