## ADX Difference

**Alexander.Gettinger** · Wed Aug 15, 2018 1:50 pm

Formula:
ADX Difference[i] = ADX[i]-ADX[i-Difference], where
ADX - Average Directional Movement Index with [Length] as number of periods.
