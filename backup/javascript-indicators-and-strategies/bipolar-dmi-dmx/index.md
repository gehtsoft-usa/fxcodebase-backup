## Bipolar DMI (DMX)

**Alexander.Gettinger** · Tue Jun 06, 2017 1:44 pm

Formulas:
DMX = (P-M)/(P+M),
Signal = MA(DMX) with [Smoothing_Length] number of periods and [Smoothing_Method] type, where
P - (+DI) mode of ADX indicator,
M - (-DI) mode of ADX indicator.
