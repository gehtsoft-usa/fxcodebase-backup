## Magic Trend indicator

**Alexander.Gettinger** · Sat Oct 28, 2017 9:39 am

IF CCI >= 0 MAGIC = max(previous MAGIC, LOW - ATR()), else MAGIC = min(previous MAGIC, HIGH + ATR()).
