## Normalized Acceleration/Deceleration

**Alexander.Gettinger** · Sat Mar 30, 2019 2:42 pm

This indicator will shift and rescale standard AC indicator.

Normalization Level
Cental Line of Normalized AC

Scale
Range of Normalized AC
If 0 is set, AC ( Max-Min) range will be used

Normalization Period
If 0 is set whole period will be used
