## Chartmill Value Indicator

**Alexander.Gettinger** · Thu Apr 12, 2018 12:03 pm

Formulas:
C[i] = (Close[i]-MA)/ATR,
H[i] = (High[i]-MA)/ATR,
L[i] = (Low[i]-MA)/ATR,
O[i] = (Open[i]-MA)/ATR, where
MA = Moving average(Median Price, Length, Method),
ATR = Average True Range(Length).
