## LRMA indicator

**Alexander.Gettinger** · Sat Oct 28, 2017 9:29 am

Smoothing algorithm of this moving averages based on linear regression.

LRMA=3*LWMA-2*MVA, where
LWMA - linear weighted moving average,
MVA - simple moving averages.
