## MA Slope indicator

**Alexander.Gettinger** · Fri Dec 07, 2018 2:07 pm

Shows the slope of MA, in Pips per period.
MASO (in Pips) = ( MA[period]- MA[period-Bar] )
if MASO > Slope then Buy;
if MASO < Slope then Sell;
else Neutral.
