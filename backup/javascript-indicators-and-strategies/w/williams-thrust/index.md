## Williams Thrust

If Williams % R (250) > EMA (50) of Williams % R (250) AND
If Williams % R (50) > EMA (10) of Williams % R (50) = Positive Thrust (Buy Signal)

If Williams % R (250) < EMA (50) of Williams % R (250) AND
If Williams % R (50) < EMA (10) of Williams % R (50) = Negative Thrust (Sell Signal)
