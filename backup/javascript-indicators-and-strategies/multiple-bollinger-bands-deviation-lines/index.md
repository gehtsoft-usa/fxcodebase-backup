## Multiple Bollinger Bands Deviation Lines

**Alexander.Gettinger** · Fri Dec 07, 2018 2:45 pm

Formulas:
U1 = MA+d,
L1 = MA-d,
U2 = MA+2*d,
L2 = MA-2*d,
U3 = MA+3*d,
L3 = MA-3*d,
U4 = MA+4*d,
L4 = MA-4*d, where
MA - moving average with [Length] number of periods and [Method] type,
d = Deviation*StdDev,
StdDev - standard deviation.
