## ConnorsRSI oscillator

**Alexander.Gettinger** · Thu Apr 12, 2018 12:04 pm

Formula:
ConnorsRSI(3,2,100) = [ RSI(Close,3) + RSI(UpDownDays,2) + PercentRank(percentMove,100) ] / 3
