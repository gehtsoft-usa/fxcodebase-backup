## Candle Ratio indicator

**Alexander.Gettinger** · Thu Apr 12, 2018 11:57 am

Up Candle
Up=close-open;
Down =0;

Down Candle
Down=open-close;
Up = 0;
Ratio = Sum(Up) / Sum (Down);
