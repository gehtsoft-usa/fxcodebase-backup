## ATR ratio

**Alexander.Gettinger** · Fri May 26, 2017 2:11 pm

Formula:
ATR ratio = ATR_S/ATR_L, where
ATR_S - Average True Range with [ShortPeriod] number of periods,
ATR_L - Average True Range with [LongPeriod] number of periods.
