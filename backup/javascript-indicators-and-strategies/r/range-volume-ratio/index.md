## Range Volume Ratio

**Alexander.Gettinger** · Sat Nov 24, 2018 3:16 pm

Formula:
RVR[i] = Abs(Open[i]-Close[i])/Volume[i], if Method="Open/Close",
RVR[i] = (High[i]-Low[i])/Volume[i], if Method="High/Low".
