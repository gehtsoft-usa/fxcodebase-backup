## Relative Spread Strength

**Alexander.Gettinger** · Fri Jun 23, 2017 2:50 pm

Formula:
RSS = MVA(RSI, Smoothing_Length), where
RSI = RSI(Short_EMA(Price)-Long_EMA(Price)).
