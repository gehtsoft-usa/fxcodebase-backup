public method instance_impl:addCopyStream

Brief

The method creates a copy of the specified output stream. The copy is shifted against the original stream horizontally and vertically by the specified levels.

Declaration
Lua
output_stream instance_impl:addCopyStream (id, type, fullName, label, color, style, width, hoffset, voffset, voosetrel, offstlevels, stream)

Parameters
id

The stream identifier. The identifier must contain only English letters or digits and must be unique within the instance of the indicator.
type

The type of the stream graphical representation. The possible values are: core.Dot, core.Line, and core.Bar.
fullName

The full name of the stream. The recommended style is: Indicator identifier(Source Name, Parameter 1, ... Parameter N).Label If the indicator has only one stream, .Label can be omitted.
label

The short name of the stream. If the indicator has only one stream, the label must be equal to the indicator identifier.
color

The color of the graphical representation of the stream. The color can be created by using the core.rgb function.
style

The style of the line that represents the stream. The possible values are:

core.LINE_NONE

An invisible line.

core.LINE_SOLID

A solid line.

core.LINE_DASH

A dash line.

core.LINE_DOT

A dot line.

core.LINE_DASHDOT

A dash-dot line.

If the stream is represented by Dot or core.Bar, the value must be 0.
width

If the type of the output stream is core.Dot or core.Line, the width of the line or dot expressed in pixels. The default line width or dot size is 1 pixel.

If the type of the output stream is core.Bar or the output stream is joined to the bar, the width of the bar as a percent of the period cell width. The default bar width is 100%.
hoffset

The horizontal offset of the stream against the original stream. The offset is expressed in periods. The positive value means that the stream is shifted to the future. The negative value means that the stream is shifted to the past. If the horizontal shift is not needed, the value must be 0.
voffset

The vertical offset of the stream against the original stream. The offset can be set as a number that is expressed in the unit of the chart vertical scale or as a percent of the original stream values. The positive value means that the stream is shifted "up", to the greater values of the vertical scale. The negative value means that the stream is shifted "down", to the smaller values of the vertical scale. If the vertical shift is not needed, the value must be 0.
voffsetrel

The parameter that defines the unit of measure of the voffset parameter. The true value means that the vertical offset is expressed in percent of the original stream values. The false value means that the vertical offset is expressed in units of the chart vertical scale.
voffsetlevels

The parameter that defines whether the original stream levels (if exist) must be shifted or not. The true value shifts the levels. The false value leaves the levels on the original positions.
stream

The instance of the output_stream to be copied and shifted.

Returns

The method returns an instance of the output_stream table.
