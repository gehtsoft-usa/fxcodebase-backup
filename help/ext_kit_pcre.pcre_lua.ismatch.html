static public method pcre_lua.ismatch

Brief

Briefly checks whether the expression matches the text.

Declaration
Lua
boolean pcre_lua.ismatch (expression, string, options?)

Parameters
expression

The regular expression.

Please see PCRE Pattern Specification for details.
string

The string to be matched.
options

The one or more options.

For the list of the options see the public constant section of the pcre_lua table.

The options can be joined using + operator.

By default, the expression is single-line, case-sensitive, in multi-byte char set and greedy.

Details

The method compiles the specified expression and then checks whether the expression matches the string specified.

The method returns true in case the expression is successfully compiled and matches the string, false in case the expression is successfully compiled does not match the string, and throws an error in case the expression cannot be compiled.

Please note that the method compiles the expression every time when the method is called. If you plan to perform this operation multiple times or you need to get the captures' values, please use the pcre_lua.compile() method.

Example: Check whether URL string is properly formed Show

Example: Check whether URL string is properly formed Hide

   --                    schema                  host               port       path         params
   local url_pattern = "(http|https|ftp):\\/\\/([\\w\\-\\._\\d]+)(:(\\d+))?((\\/[^\\?\\s]*)(\\?\\S+)?)?";
   -- schema is http or https or ftp (match 1)
   -- host is text of letters, number, dashes and underscores until : / or a space (match 2)
   -- port is optional and is a set number preceded with colon (match 4)
   -- path is optional is started with with / after the host and port and goes until
   -- a question mark or a space (match 6)
   -- parameters are optional and goes after the patch starting with a question mark
   -- and goes until a space character (match 7)
 
   assert(pcre_lua.ismatch(url_pattern, "http://www.google.com", pcre_lua.CASELESS), "must match");
   assert(pcre_lua.ismatch(url_pattern, "http://www.google.com:8080/", pcre_lua.CASELESS), "must match");
   assert(pcre_lua.ismatch(url_pattern, "http://www.google.com/search", pcre_lua.CASELESS), "must match");
   assert(pcre_lua.ismatch(url_pattern, "http://www.google.com:8080/search", pcre_lua.CASELESS), "must match");
   assert(pcre_lua.ismatch(url_pattern, "http://www.google.com:8080/search?query=A+B", pcre_lua.CASELESS), "must match");
   assert(not(pcre_lua.ismatch(url_pattern, "wrong://www.goo gle.com:8080/search?query=A+B", pcre_lua.CASELESS)), "must not match");
