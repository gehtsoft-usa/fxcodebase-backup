public method context:drawText

Brief

Draws a text.

Declaration
Lua
context:drawText (font, text, color, background, x1, y1, x2, y2, style, transparency?)

Parameters
font

The index of the font.

The font must be created using createFont method.
text

The text to be drawn.
color

The foreground color of the text.
background

The color of the background for the text area or -1 for transparent background.
x1

The X coordinate of the top-left corner of the text rectangle.
y1

The Y coordinate of the top-left corner of the text rectangle.
x2

The X coordinate of the bottom-right corner of the text rectangle.

Note: To get width and height of the text, use the measureText method.
y2

The Y coordinate of the bottom-right corner of the text rectangle.
style

The style of the text. You can use one or a combination of the of the following parameters. Use + to combine the parameters.

context.LEFT

Aligns text to the left.

context.RIGHT

Aligns text to the right.

context.CENTER

Centers text horizontally in the rectangle.

context.TOP

Justifies the text to the top of the rectangle.

context.BOTTOM

Justifies the text to the bottom of the rectangle. This value is used only with the SINGLELINE value.

context.VCENTER

Centers text vertically. This value is used only with the SINGLELINE value.

context.NOPREFIX

Turns off processing of prefix characters. Normally, the method interprets the mnemonic-prefix character & as a directive to underscore the character that follows, and the mnemonic-prefix characters & as a directive to print a single &. By specifying NOPREFIX, this processing is turned off. For example,
input string: "A&bc&d"
normal: "Abc&d"
DT_NOPREFIX: "A&bc&d"

context.SINGLELINE

Displays text on a single line only. Carriage returns and line feeds do not break the line.

context.RTLREADING

Layout in right-to-left reading order for bi-directional text when the font is a Hebrew or Arabic font. The default reading order for all text is left-to-right.

context.EXPANDTABS

Expands tab characters. The number of characters per tab is eight. The PATH_ELLIPSIS, and END_ELLIPSIS values cannot be used with the EXPANDTABS value.

context.END_ELLIPSIS

For displayed text, if the end of a string does not fit in the rectangle, it is truncated and ellipses are added. If a word that is not at the end of the string goes beyond the limits of the rectangle, it is truncated without ellipses.

context.PATH_ELLIPSIS

For displayed text, replaces characters in the middle of the string with ellipses so that the result fits in the specified rectangle.

If the string contains backslash (\) characters, PATH_ELLIPSIS preserves as much as possible of the text after the last backslash.

context.WORDBREAK

Breaks words. Lines are automatically broken between words if a word would extend past the edge of the rectangle specified by the lpRect parameter. A carriage return-line feed sequence also breaks the line.

If this is not specified, output is on one line.
transparency?

Transparency of the paintings performed by the method. The value must be a number between 0 and 255. 0 means the opaque paintings (the paintings hides everything below), 255 means the completely transparent paintings (the painting is not visible). The values between these values defines transparency of the painting, the bigger number means more transparency.

The parameter is optional. If the default transparency is 0.

Use transparency only if you actually need it for your goals. Please remember that semi-transparent painting procedure is much slower than opaque drawing.
