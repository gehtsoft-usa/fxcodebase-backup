static public method indicore3_ffi.odcontext_drawLine

Brief

The function draws a line.

Declaration
Lua
void indicore3_ffi.odcontext_drawLine (void *context, int pen, int x1, int y1, int x2, int y2, int transparency)

Parameters
context

The context object.
pen

The identifier of the pen object. The pen object can be created by using the indicore3_ffi.odcontext_createPen function. Use -1 identifier for the null (invisible) pen.
x1

The x-coordinate of the line start point.
y1

The y-coordinate of the line start point.
x2

The x-coordinate of the line end point.
y2

The y-coordinate of the line end point.
transparency

Transparency of the paintings performed by the function. The value must be a number between 0 and 255. 0 means the opaque paintings (the paintings hides everything below). 255 means the completely transparent paintings (the painting is not visible). The values between these values defines transparency of the painting, the bigger number means more transparency.

Use transparency only if you actually need it for your goals. Please remember that semi-transparent painting procedure is much slower than opaque drawing.
