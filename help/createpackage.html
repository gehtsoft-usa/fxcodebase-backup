How to Create Package?

Brief

The article describes how to create a package from your project.

Details

When you decided to create a package the first thing you need to do is to select the nested indicators that will be the public, i.e. available in the Marketscope 2.0 application as separate, complete indicators. If all nested indicators are supposed to be hidden, i.e. unavailable in the Marketscope 2.0 application, you may omit this step. All nested indicators are marked to be hidden by default.

To select nested indicators to be the public

  1. Right-click in the project tree area and then click Properties.

  2. The Properties dialog box appears.

  3. Click the Public Package Files tab.

  4. Select check boxes next to the indicators files you want to make public.

  5. Click OK.

You can also select a strategy or/and nested indicators which source code you want to protect. In this case the source code is saved as binary files.

To select a strategy or/and nested indicators to be saved as binary files

  1. Right-click in the project tree area and then click Properties.

  2. The Properties dialog box appears.

  3. Click the Compiled Package Files tab.

  4. Select check boxes next to the strategy or/and nested indicators files the source code of which you want to protect.

  5. Click OK.

When the publicity of the nested indicators and the source code to be protected are defined, you can create a package. Note that your selection will be saved in the project at the next time you save the project.

To create a package

  1. Do one of the following:

    • On the toolbar, click the Create Package button.

    • On the Project menu, click Create Package.

  2. The Save As dialog box appears.

  3. In the Save in box, select the folder in which you want to save the package.

  4. In the File name box, type the name of the package file.

  5. Click Save.
