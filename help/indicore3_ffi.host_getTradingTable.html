static public method indicore3_ffi.host_getTradingTable

Brief

The function returns the specified trading table.

Declaration
Lua
void * indicore3_ffi.host_getTradingTable (void *host, void *instance, const char *name)

Parameters
host

A pointer to the host which the indicator or strategy requests for the table.
instance

A pointer to the indicator or strategy instance by which the table is requested.
name

An identifier of the table. The possible values are:

"accounts"

The trading accounts.

"orders"

The pending orders.

"offers"

The instruments and the most recent bid/ask prices.

"trades"

The opened trades.

"closed trades"

The most recently closed trades.

"messages"

The messages.

"summary"

The trades summary.

Returns

The function returns a pointer to the requested trading table. If the specified table does not exist, the function returns nil.

Details

The function can be used in indicators and strategies.

The following functions are intended to work with the returned table:

Function

Description

indicore3_ffi.tradingtable_enumerator()

The function creates an enumerator for the table.

indicore3_ffi.tradingtable_findRow()

The function searches for a row with the specified column value.

indicore3_ffi.tradingtable_findAll()

The function searches for rows with the specified column value.

indicore3_ffi.tradingtable_version()

The function returns the version of the table content. The version changes each time when a row is added or deleted from the table.

The table must be released when it is no longer needed by using the indicore3_ffi.core_object_release() function.

For details about trading tables, see the Trading Tables section.
