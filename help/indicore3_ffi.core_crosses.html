static public method indicore3_ffi.core_crosses

Brief

The function check whether the stream crosses the other stream in any direction at the specified period.

Declaration
Lua
bool indicore3_ffi.core_crosses (void *stream1, void *stream2, int period1, int period2)

Parameters
stream1

The first stream. The stream must be the tick_stream, or output_stream, or output_stream_impl.
stream2

The second stream. The second stream. The stream must be the tick_stream, or output_stream, or output_stream_impl.
period1

The index of the period in the first stream.
period2

The index of the period in the second stream. If the parameter is omitted, the period1 value is used.

Returns

The function returns the true value if the first stream crosses the second stream at the specified period. Otherwise, the function returns the false value.

Details

Note: The function also checks the previous values of the streams. So, the indexes of the specified periods must be greater than the stream_first() values of the streams.
