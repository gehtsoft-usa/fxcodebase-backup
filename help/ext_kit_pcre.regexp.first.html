public method regexp:first

Brief

Find the first match in the string specified.

Declaration
Lua
integer regexp:first (string)

Parameters
string

The string to be matched.

Details

The method finds the first of the matches in the string specified. The method returns the number of captures or 0 in case the string has no matches to the expression.

The first capture is the whole part of the text which matches the whole expression. Other captures are corresponding to the regular expression groups (a part of the pattern enclosed into the brackets) and are indexed from the left to right. I.e. the first left bracket starts the second capture and so on.

To get the captures use regexp:match_pos() and regexp:match_text() methods.

To find the next match in the same string use regexp:next() method.

Example: Use first/next methods to find all matches Hide

 
   -- expression which finds the day in
   -- yy-mm-dd, yyyy-mm-dd, yy-mmm-dd or yyyy-mmm-dd formats
   local exp = pcre_lua.compile("(((\\d\\d)?\\d\\d)-(((\\d\\d?)|(jan|feb|mar|apr|may|jun|jul|aug|sep|oct|nov|dec)))-(\\d\\d?))", pcre_lua.CASELESS + pcre_lua.MULTILINE);
   local text = "2010-11-22 text 2009-1-1 another text 2000-jan-01 and in final now 1999-Dec-31";
   local matches;
 
   matches = exp:first(text);
   while matches > 0 do
       print("Match found!!!\n");
       for i = 0, matches - 1, 1 do
           local pos, len, text;
           pos, len = exp:match_pos(i);
           text = exp:match_text(i);
           print(string.format("  %i (%i, %i) %s\n", i, pos, len, text));
       end
   end
   matches = exp:next();
