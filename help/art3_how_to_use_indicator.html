How to Use Another Indicator in Your Code?

Brief

The section provides guidlines for using other indicators in your own code.

Details

Sometimes,it is helpful to reuse other indicator in your code to avoid repetition. For example, the MACD indicator uses the EMA indicator three times for different values.

If you need to apply another indicator on your indicator source, you must:

1) Create an instance of the indicator in your Prepare() function. You can use indicator manager to create the indicator.

Example: Indicator creation example Hide

   local mva7;                 -- the output stream of the MVA(7) indicator
   local stream;               -- the output stream of your indicator
   function Prepare()
       mva7 = core.indicators:create("MVA", source, 7);
       -- Create your own stream.
       stream = instance:addStream("MVA72", core.Line, "MVA(7)/2", "MVA(7)/2", instance.parameters:getColor("C"),  7);
   end

2) Since you own the new indicator, you must also control updating of this indicator manually:

Note 1) Of course, you can apply the indicator to your own output stream (or internal stream) instead of your source stream. But, in this case, you should call update of the subsequent indicator only after you have calculated values of your output stream.

Note 2) Sometimes (for example, when the source collection is extended to the left), your indicator is executed to be updated completely. Your subsequent indicators must also be updated completely in this case. To control this process, you can use the values core.UpdateLast and core.UpdateAll of the Mode parameter. The value core.UpdateLast indicates that your indicator is called to update the last currently existing value, and the value core.UpdateAll indicates that your indicator is called to completely recalculate the output.

   function Update(period, mode)
       mva7:update(mode);
       if (period >= 7) then
           -- Write half of the MVA value to your output stream.
           stream[period] = mva7.DATA[period] / 2;
       end
   end

Sometimes, you might need to apply another indicator on some pre-calculated data, for example on a median ((open + high + close) / 3).

In that case you must:

1) Create a internal stream to keep pre-calculated data.

2) Apply the indicator on this stream.

3) In the Update function, you must fill the internal stream and only then call the indicator's update function.

Note: In case, you have to apply an indicator on the output value of another indicator, you must call the update function in the same order as indicators were created.

The example below show the simple indicator which uses exponential moving average for double smoothing of the median value.

-- Indicator profile initialization routine
function Init()
    indicator:name("Example");
    indicator:description("Double smoothed median value");
    indicator:requiredSource(core.Bar);
    indicator:type(core.Indicator);
 
    indicator.parameters:addInteger("N", "Number of the periods for the first EMA", "", 7, 2, 500);
    indicator.parameters:addInteger("M", "Number of the periods for the second EMA", "", 7, 2, 500);
    indicator.parameters:addColor("S1_color", "Color of S1", "Color of S1", core.rgb(255, 0, 0));
end
 
-- Indicator instance initialization routine
 
-- parameter for the first ema
local N;
-- parameter for the second ema
local M;
-- the first available data (source first + ema1 shift + ema2 shift)
local first;
-- the source
local source = nil;
-- ema instances
local ema1 = nil;
local ema2 = nil;
-- output streams
local S1 = nil;
-- median stream
local median = nil;
 
-- Routine
function Prepare()
    N = instance.parameters.N;
    M = instance.parameters.M;
    source = instance.source;
 
    -- create a stream to keep the median
    median = instance:addInternalStream(source:first(), 0);
    -- apply the first EMA on the median
    ema1 = core.indicators:create("EMA", median, N);
    -- apply the second EMA on the first EMA result
    ema2 = core.indicators:create("EMA", ema1.DATA, M);
 
    first = ema2.DATA:first();
    local name = profile:id() .. "(" .. source:name() .. ", " .. N .. ", " .. M .. ")";
    instance:name(name);
    -- create the indicator output
    S1 = instance:addStream("S1", core.Line, name, "S1", instance.parameters.S1_color, first);
end
 
-- Indicator calculation routine
function Update(period, mode)
    if period >= first and source:hasData(period) then
        -- calculate the median value for the period
        median[period] = (source.high[period] + source.low[period] + source.close[period]) / 3;
        -- first pass of ema
        ema1:update(mode);
        -- second pass of ema
        ema2:update(mode);
        -- copy the second pass ema to the output
        S1[period] = ema2.DATA[period];
    end
end
