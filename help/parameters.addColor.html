public method parameters:addColor

Brief

Adds a new color parameter.

Declaration
Lua
parameters:addColor (id, name, description, defaultValue)

Parameters
id

string: The unique identifier of the parameter.
name

string: The short name of the parameter.
description

string: The detailed description of the parameter.
defaultValue

integer: The default value of the parameter.

You can also use the core.COLOR_LABEL, core.COLOR_LINE, core.COLOR_UPCANDLE, core.COLOR_DOWNCANDLE, core.COLOR_CUSTOMLEVEL, core.COLOR_BACKGROUND to use the Marketscope's default colors.

For setting color by the name you can use a table returned by core.colors() method.

Details

Example Show

Example Hide

 
   function Init()
 
       local colors = core.colors();
       -- specify default value of the color by it's absolute value
       indicator.parameters:addColor("MyColor1", "Color 1", "", core.rgb(255, 0, 0));
       -- specify default value of the color via colors table
       indicator.parameters:addColor("MyColor2", "Color 2", "", colors.DeepPink);
       -- force application to use the default color of the ascending candle from the application options
       indicator.parameters:addColor("MyColor3", "Color 3", "", core.COLOR_UPCANDLE);
