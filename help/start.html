How to Start Creating an Indicator in SDK?

Brief

The section describes how to start creating an indicator in Indicore 3 Lua Editor/Debugger.

Details

Indicator source code is created and modified in Indicore 3 Lua Editor/Debugger.

You shall write the indicator source code on the basis of a template. A template is automatically generated after you specify settings for a new indicator. You can also start from a blank template.

To generate a template

  1. Do one of the following:

    • On the toolbar, click the New Indicator button.

    • On the File menu, point to New, and then click Indicator.

  2. The Save As dialog box appears.

  3. In the Save in box, select the folder in which you want to save the indicator file.

  4. In the File name box, type the name of the file, and then click Save.

  5. The New Indicator dialog box appears.

  6. To specify the indicator settings and generate the template, click Create using the Wizard, and then click OK.

    To start from the blank template, click Create empty file, and then click OK.
    In this case you can start writing the indicator.

  7. The New Indicator dialog box appears.

  8. In the Type box, select the type of the indicator.

  9. In the Required box, select the type of the indicator source stream.

  10. Add at least one output stream.
    To add an output stream

    • Click the Add button under the Streams box.

    • The Stream dialog box appears.

    • In the Unique box, type the name of the stream.

    • In the Type box, select the graphical representation of the stream on a chart.

    • Click OK.

    • The steam is added to the Streams box.

  11. Define the following indicator settings of your choice:

    • In the Displayable Name box, type the user-friendly name of the indicator.

    • In the Description box, type the user-friendly description of the indicator.

    • To create a resource file for the localization support of your indicator, select the Create Resource check box.

    • Define parameters of the indicator.
      To define a parameter

      • Click the Add button under the Parameters box.

      • The Parameter dialog box appears.

      • In the Unique Identifier box, type the name of the parameter.

      • In the Displayable Name box, type the user-friendly name of the parameter.

      • In the Description box, type the user-friendly description of the parameter.

      • In the Type box, select the type of the parameter.

      • In the Default box, type the default value of the parameter.

      • Click OK.

      • The parameter is added to the Parameters box.

  12. Click OK.

The generated source code with the specified settings is displayed in the Lua Editor/Debugger window. The source code is written in the Lua language. To learn more about the language, see the Lua 5.1 Reference Manual.

When you start to write a new indicator (or you open an existing indicator) a new project is created. For details, see the How to Work with Project? section.
