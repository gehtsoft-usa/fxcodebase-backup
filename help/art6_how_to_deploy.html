How to Install and Use Your Indicator in Marketscope?

Brief

The section describes how to use your indicator in Marketscope.

Details

After you complete writing of the indicator source code and make sure that it has no errors, you can use the indicator or strategy in the trading platform FX Trading Station II with the integrated charting application Marketscope 2.0.

To be able to use your indicator or strategy, it is necessary to import it to the application first.

To import an indicator or strategy

  1. Do one of the following:

    • In Marketscope, on the Alerts and Trading Automation menu, click Import Extension.

    • In the FX Trading Station, on the Charts menu, point to Alerts and Trading Automation, and then click Import Extension.

  2. The Open dialog appears.

  3. In the File name box, type the name of the indicator or strategy file you want to import or browse for one, and then click Open.

  4. The Install Extension dialog box appears.

  5. Click Install.

  6. The Extension has been installed message box appears.

  7. Click OK.

    Note: If an error occurs, the Extension Import Errors message box appears providing the extension ID and the error description.

To add your indicator to a chart

  1. Do one of the following:

    • On the toolbar, click the Add Indicator button.

    • On the Insert menu, click Add Indicator.

    • Right-click in the chart, and then click Add Indicator.

    • Press I.

  2. The Add Indicator dialog box appears.

  3. Select your indicator in the list of indicators.
    Note: When you add the indicator to the list of indicators, it appears at the beginning of the list by default.

  4. Change indicator parameters and settings, if necessary.

  5. Click OK.

To add your strategy

  1. On the Alerts and Trading Automation menu, click New Strategy or Alert.

  2. The New Strategy or Alert dialog box appears.

  3. Select your strategy in the list of indicators.
    Note: When you add the indicator to the list of indicators, it appears at the beginning of the list by default.

  4. Change strategy parameters and settings, if necessary.

  5. Click OK.

Errors may occur when an indicator is added to the chart; in this case, you will see an error message with the error details.

Besides, errors may occur:

  • During calculation of an indicator for price change;

  • During loading of the FX trading station - an indicator, both custom and standard, may fail to load.

  • During loading of a saved chart template, snapshot or layout - a custom indicator may fail to load (for example, for the reason that the indicator was removed from the list of indicators in the period between saving and loading of the chart template, snapshot or layout). These errors are stored in events log.

To view the Events Log

  1. Do one of the following:

    • In Marketscope, on the Alerts and Trading Automation menu, click Show Events.

    • In the FX Trading Station, in the Charts menu, point to Alerts and Trading Automation, and then click Show Events.

  2. The Events window appears.

  3. Click the Log tab.

To learn more about working with Marketscope charts, see Marketscope 2.0 Help.
