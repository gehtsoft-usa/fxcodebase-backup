public method parameters:setFlag

Brief

Sets the parameter's flag

Declaration
Lua
parameters:setFlag (id, flag)

Parameters
id

string: The id of the previously created parameter.
flag

string: The parameter's flag

Details

The flag changes behavior of the parameter. The following flags are supported:

core.FLAG_INSTRUMENTS

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the instrument. The user will see a list of all available instruments and will be able to choose one of them. The instrument name will be returned as a value of the parameter.

core.FLAG_PERIODS

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the period (bar sizes). The user will see a list of all available bar sizes and will be able to choose one of them. The bar size code (see tick_stream:barSize() for details) will be returned as a value of the parameter.

core.FLAG_BARPERIODS

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the period (bar sizes) with no tick periods option. The user will see a list of all available bar sizes except tick periods and will be able to choose one of them. The bar size code (see tick_stream:barSize() for details) will be returned as a value of the parameter.

core.FLAG_PERIODS_EDIT

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the period (bar sizes). The user will see a list of all available bar sizes and will be able to choose one of them. The bar size code (see tick_stream:barSize() for details) will be returned as a value of the parameter.

The user must be able as choose a period from the list of the periods or enter a custom period identifier (such as m3 or H12).

core.FLAG_BARPERIODS_EDIT

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the period (bar sizes). The tick period is not included. The user will see a list of all available bar sizes and will be able to choose one of them. The bar size code (see tick_stream:barSize() for details) will be returned as a value of the parameter.

The user must be able as choose a period from the list of the periods or enter a custom period identifier (such as m3 or H12).

core.FLAG_BIDASK

The flag is applicable to the string parameter. The flag turns the string parameter into a choice of the price type (bid or ask).

core.FLAG_ACCOUNT

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the user accounts.

The parameter will be filled with the account identifier (AccountID of the Accounts table).

core.FLAG_ORDER

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the pending orders.

The parameter will be filled with the order identifier (OrderID of the Orders table).

core.FLAG_TRADE

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the exisiting trades.

The parameter will be filled with the trade identifier (TradeID of the Trades table).

core.FLAG_INDICATOR

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the indicator. The user will see a list of all available indicators and will be able to choose one of them. The identifier of the indicator will be returned as a value of the parameter. The selected parameter values for the indicator can be retrieved using the getCustomParameters method.

core.FLAG_ONLYINDICATORS

Works as core.FLAG_INDICATOR but includes only indicators (not oscillators) into the list to choose.

core.FLAG_ONLYOSCILLATORS

Works as core.FLAG_INDICATOR but includes only indicators (not oscillators) into the list to choose.

core.FLAG_STRATEGY

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the signal. The user will see a list of all available signals and will be able to choose one of them. The identifier of the signal will be returned as a value of the parameter. The selected parameter values for the signal can be retrieved using the getCustomParameters method.

core.FLAG_SOUND

The flag is applicable to the file parameter. This flag turns the file parameter into a choice of the sound file. The user will see a dialog to choose a sound file. The path to the sound file will be returned as a value of the parameter.

core.FLAG_EMAIL

The flag is applicable to the string parameter. This flag turns the string parameter into a choice of the email address.

core.FLAG_LINE_STYLE

The flag is applicable to the integer parameter. This flag turns the integers parameter into a choice of the line styles. The choice includes all line styles except "none".

core.FLAG_LEVEL_STYLE

The flag is applicable to the integer parameter. This flag turns the integers parameter into a choice of the line styles. The choice includes all line styles

core.FLAG_PRICE

The flag is applicable to the double parameter. The flag is applicable to strategy parameters only. In case the flag is applied, during editing of the default value of the parameter will be changed every time when the price of the strategy's instrument is changed (i.e. it behaves as a rate fields of the Trading Station order dialogs).

core.FLAG_ALLOW_TRADE

The flag is applicable to the Boolean parameter.

The flag indicates that the Boolean parameter is used to allow the strategy to trade.

core.FLAG_DATE

The flag is applicable to the date parameter.

User can enter date only. The date is not nullable.

core.FLAG_DATE_OR_NULL

The flag is applicable to the date parameter.

User can enter date only. The input field must contain an on/off selector. If the selector is on, the date can be modified and its value will be returned. If the selector is off, the date cannot be modified and zero value will be returned.

core.FLAG_DATETIME

The flag is applicable to the date parameter.

User can enter date and time. The date is not nullable.

core.FLAG_DATETIME_OR_NULL

The flag is applicable to the date parameter.

User can enter date and time. The input field must contain an on/off selector. If the selector is on, the date can be modified and its value will be returned. If the selector is off, the date cannot be modified and zero value will be returned.
