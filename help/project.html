How to Work with Project?

Brief

The section describes what is a project, the project solutions, and contains the description of operations you can perform with the project.

Details

When you create a new indicator/strategy or open an existing one you can save it as a project. The project is a container that links a source code of your indicator/strategy with a code of nested indicators. It also keeps settings of the indicator/strategy debugging sessions.

The main feature of the project is the ability to create a package that includes all indicators or/and strategy from your project. When you create the package you can choose which nested indicators will be the public (available as separate, complete indicators in the Marketscope 2.0 application) and which will be hidden (used only by your indicator/strategy). It is extremely useful when you use a particular version of a custom indicator as a nested indicator in your project. The custom indicator (the other version of it) can be used in Marketscope without any conflicts as well.

The project is also useful for the debugging. It enables you:

  • Debug nested indicators of your choice.

  • Save and reuse parameters of your indicator/strategy specified during the last debugging session.

  • Save and reuse watches and break points previously specified.

To save an indicator or strategy as a project

  1. Do one of the following:

    • On the toolbar, click the Save All button.

    • On the File menu, click Save Project.

  2. The Save dialog box appears.

  3. Click OK.

  4. The Save As dialog box appears.

  5. In the Save in box, select the folder in which you want to save the project.

  6. In the File name box, type the name of the project file.

  7. Click Save.
