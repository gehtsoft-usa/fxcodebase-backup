How to Support Localization?

Brief

The section provides guidlines for supporting localization of your indicator.

Details

Your indicator has to return human-readable text such as the name of the indicator, its description and so on. The localization enables you to provide the same text in different languages.

The first step is to translate this text into all languages you want to support. One of these languages must be used as the default language, i.e. the language in which the text must be shown in case you do not provide text of a particular language.

The file with the text for all supported languages is called a resource file. The resource file must have exactly the same name as your indicator plus the extension .rc. For example, if your indicator has the name mva.lua, your resource file must have the name mva.lua.rc. The resource file must be a text file in the UTF-8 encoding. You can use the notepad.exe text editor to create resource files. The resource file must be placed into the same folder as your indicator.

[esp]

name=Media Movil Simple
param_N_name=Numero Periodos
param_clrDIP_name=Color de la linea
[fra]
codepage=1252
name=Moyenne mobile simple
param_N_name=Nombre de periodes
param_clrDIP_name=Couleur de la ligne

The first line of the file declares the default language.

All texts are grouped by the language. The identifier of the language is specified in square brackets before all texts. The line with the language identifier is followed by a line containing the code page of the language. All texts of type name=text are specified one-by-one after the line containing the code page. The name of the text will be used in the indicator code instead of the text.
