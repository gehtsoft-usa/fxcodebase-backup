Summary(table)

Brief

The section describes the "Summary" table.

Details

The table includes summarized information about the average entry price and profit/loss for every instrument traded.

Name

Type

Description

OfferID

String

The unique number of the instrument that has open position(s).

DefaultSortOrder

Integer

The sequence number of the instrument in the list of instruments displayed to the FX Trading Station user.

Instrument

String

The symbol indicating the instrument. For example, EUR/USD, USD/JPY, GBP/USD.

SellNetPL

Double

The current profit and loss on all positions opened in the instrument with the direction set to "sell". Commissions and interest are not taken into consideration. SellNetP/L is expressed in the account currency.

SellAmountK

Double

The trade amount of all positions opened in the instrument with the direction set to "sell".

Forex: SellAmountK is expressed in the base currency of the instrument, and is displayed in thousands. For example, 50 for EUR/USD means that the total trade amount of all sell positions opened in EUR/USD is 50,000 Euros.

CFD: With CFD, the amount of the order is expressed in the number of contracts. The value is also displayed in thousands.

SellAvgOpen

Double

The average open price of positions opened in the instrument with the direction set to "sell".

BuyAvgOpen

Double

The average open price of positions opened in the instrument with the direction set to "buy".

BuyAmountK

Double

The trade amount of all positions opened in the instrument with the direction set to "buy".

Forex: BuyAmountK is expressed in the base currency of the instrument, and is displayed in thousands. For example, 50 for EUR/USD means that the total trade amount of all buy positions opened in EUR/USD is 50,000 Euros.

CFD: With CFD, the amount of the order is expressed in the number of contracts. The value is also displayed in thousands.

BuyNetPL

Double

The current profit and loss on all positions opened in the instrument with the direction set to "buy". Commissions and interest are not taken into consideration. BuyNetP/L is expressed in the account currency.

AmountK

Double

Forex: The trade amount of all positions (both buy and sell) opened in the instrument. AmountK is expressed in the base currency of the instrument. For example, 50 for EUR/USD means that the total trade amount of all positions opened in EUR/USD is 50,000 Euros.

CFD: With CFD, the amount of the order is expressed in the number of contracts. The value is also displayed in thousands.

GrossPL

Double

The current profit and loss on all positions (both buy and sell) opened in the instrument, without taking into consideration the commissions and interest. GrossPL is expressed in the account currency.

NetPL

Double

The current profit and loss on all positions (both buy and sell) opened in the instrument, including commissions and interest. NetPL is expressed in the account currency.
