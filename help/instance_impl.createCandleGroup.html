public method instance_impl:createCandleGroup

Brief

The method groups four or five output streams into a candle.

Declaration
Lua
instance_impl:createCandleGroup (label, id, open, high, low, close, volume?, barSize?, isBar?)

Parameters
label

The short name of the group.
id

The identifier of the group. The identifier must contain only English letters or digits and must be unique within the instance of the indicator.
open

The output stream that contains the open values of the candles. The stream must be created by using the addStream() or the addInternalStream() method.

Note that the open stream defines the graphical representation of the group. The color, breaks, and visibility of the stream are applied to the whole group.
high

The output stream that contains the high values of the candles. The stream must be created by using the addStream() or the addInternalStream() method.
low

The output stream that contains the low values of the candles. The stream must be created by using the addStream() or the addInternalStream() method.
close

The output stream that contains the close values of the candles. The stream must be created by using the addStream() or the addInternalStream() method.
volume

Optional. The output stream that contains the volume values of the candles. The stream must be created by using the addStream() or the addInternalStream() method.
barSize

Optional. The time frame of the periods. The parameter is applicable only for a view indicator. The value is the string that defines the time frame of the period. The first letter is an item, then the number which is number of items:

Y

A year.

M

A month.

D

A day.

W

A week.

H

Hours.

m

Minutes.

For example, D1 means one day period, m30 - 30 minutes period, etc.
isBar

Optional. The graphical representation of the group. The parameter is applicable only for a view indicator. The group is drawn as a bar if the value is true. The group is drawn as a candle if the value is false. The default value is false.

Details

Four (or five) output streams can be grouped into a candle group. In this case, the Japanese candles (or bars) are drawn on the chart instead of lines. The output candle group is also recognized as complete source bar stream for other indicators.

The candle group is drawn according the default system settings, but you can override the color of each particular bar by using the output_stream_impl:setColor() method of the open output stream.

If you want to replace the currently shown chart by these candles, use indicator:setTag("replaceSource", "t"); call in the Init() function of your indicator.

   function Init()
       indicator:name("sample indicator");
       indicator:description("");
       indicator:requiredSource(core.Bar);
       indicator:type(core.Indicator);
 
       indicator.parameters:addInteger("N", "Number of periods to calculate SMA", "", 7, 1, 300);
       indicator.parameters:addColor("clr", "MVA color", "", core.rgb(0, 0, 255));
       indicator.parameters:addColor("clrA", "Ascending color", "", core.COLOR_UPCANDLE);
       indicator.parameters:addColor("clrD", "Descending color", "", core.COLOR_DOWNCANDLE);
   end
 
   local source;
   local o, h, l, c, v;
   local mva;
   local n;
   local first;
 
   function Prepare()
       n = instance.parameters.N;
       source = instance.source;
       first = source:first() + n - 1;
       local name = profile:id() .. "(" .. source:name() .. "," .. n .. ")";
       instance:name(name);
 
       o = instance:addInternalStream(first + 1, 0);
       h = instance:addInternalStream(first + 1, 0);
       l = instance:addInternalStream(first + 1, 0);
       c = instance:addInternalStream(first + 1, 0);
       v = instance:addInternalStream(first + 1, 0);
       instance:createCandleGroup(source:name(), source:name(), o, h, l, c, v);
 
       -- create dummy stream just to make the indicator label colored
       mva = instance:addStream("mva", core.Line, name, "mva", instance.parameters.clr, first);
   end
 
   function Update(period, mode)
       if period >= first then
           mva[period] = mathex.avg(source.close, period - n + 1, period);
           if period >= first + 1 then
               o[period] = source.open[period];
               c[period] = source.close[period];
               h[period] = source.high[period];
               l[period] = source.low[period];
               v[period] = source.volume[period];
               if mva[period] >= mva[period - 1] then
                   o:setColor(period, instance.parameters.clrA);
               else
                   o:setColor(period, instance.parameters.clrD);
               end
           end
       end
   end
