static public method mathex.meandev

Brief

Calculates the mean deviation of the stream values in the specified range.

Declaration
Lua
number mathex.meandev (stream, range, to?)

Parameters
stream

The stream of ticks.
range

Can be either the range table or the index of the period to calculate the value from.

The range can be created using core.range, core.rangeTo, or core.rangeFrom methods.
to

If range parameter is a number, the parameter must contain the index of the period to calculate the value to.

Details

Please note that all the periods inside the range specified must conform the following rule: stream:first() <= index <= stream:size() - 1

Example: Calculate the mean deviation of the last N periods using core.rangeTo method Show

Example: Calculate the mean deviation of the last N periods using core.rangeTo method Hide

   local N;
   local first;
   local source;
 
   function Prepare()
       ...
       source = instance.source;
       first = source:first() + N - 1;
       ...
   end
   ...
   function Update(period, mode)
       ...
       if period >= first then
           local range = core.rangeTo(period, N);
           local s;
           if source:isBar() then
               s = mathex.meandev(source.close, range);
           else
               s = mathex.meandev(source, range);
           end
       end
       ...
   end

For the performance reason it is recommended to:

  • Use 3-parameters version of the call

  • Do check of the source type once in the prepare method.

Example: Calculate the mean deviation of the last N periods using from/to values Show

Example: Calculate the mean deviation of the last N periods using from/to values Hide

   local N;
   local first;
   local source;
   local tsource;
 
   function Prepare()
       ...
       source = instance.source;
       if source:isBar() then
          tsource = source.close;
       else
          tsource = source;
       end
       first = source:first() + N - 1;
       ...
   end
   ...
   function Update(period, mode)
       ...
       if period >= first then
           local s;
           s = mathex.meandev(tsource, period - N + 1, period);
           ...
       end
   end
