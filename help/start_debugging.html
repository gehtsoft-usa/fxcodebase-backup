How to Execute an Indicator or Strategy Program?

Brief

The section describes how to execute an indicator or strategy program in Indicore 3 Lua Editor/Debugger.

Details

To start debugging of an indicator or strategy, you must open it in Indicore 3 Lua Editor/Debugger.

To open an indicator or strategy

  1. Do one of the following:

    • On the toolbar, click the Open File button.

    • On the File menu, point to Open, and then click File.

  2. The Open dialog box appears.

  3. In the Look in box, select the folder where the indicator or strategy file is located.

  4. Click the file, and then click Open.

If the indicator or strategy has been saved as a project you can open it in the following way:

To open a project

  1. Do one of the following:

    • On the toolbar, click the Open Project button.

    • On the File menu, point to Open, and then click Project.

  2. The Open dialog box appears.

  3. In the Look in box, select the folder where the project file is located.

  4. Click the file, and then click Open.

If the indicator or strategy is included into a package you can open it in the following way:

To extract files from a package

  1. Do one of the following:

    • On the toolbar, click the Open File button.

    • On the File menu, point to Open, and then click File.

  2. The Open dialog box appears.

  3. In the Files of type box, select Package Files (*.ipk).

  4. In the Look in box, select the folder where the package file is located.

  5. Click the file, and then click Open.

  6. The Browse For Folder dialog box appears.

  7. Select the folder to which the files from package you want to extract.

    You can also create a new folder by clicking the Make New Folder button.

  8. The Choose Main Indicator/Strategy dialog box appears.

  9. Click the source file of the indicator or strategy you want to debug.

  10. Click OK

At this step, the debugger loads the indicator/strategy or package and checks them for syntax errors. If the errors are founded in the source code, their descriptions are displayed in the Output window. The execution of the source code can be started only after all errors are corrected.

Now, you can start the execution of the program.

If you want to see the final result, execute the source code without a breakpoint.

If you want to break the execution at a certain line of source code, use a breakpoint. To learn how to use a breakpoint, see the section How to Use Breakpoints?

If you want to monitor the run-time behavior of your program by breaking execution, execute the source code line by line.

To execute source code to the end or until a breakpoint is reached

  • Do one of the following:

    • On the toolbar, click the Run button.

    • On the Debug menu, click Run.

    • Press F5.

To execute the source code line by line
Note: If the current line is a function call the debugger steps into associated code.

  • Do one of the following:

    • On the toolbar, click the Step button.

    • On the Debug menu, click Step.

    • Press F8.

To execute the source code line by line:
Note: If the current line is a function call the debugger executes the function without stepping into it.

  • Do one of the following:

    • On the toolbar, click the Step Over button.

    • On the Debug menu, click Step Over.

    • Press F10.

You can specify variable names and expressions that you want to watch during execution of source code. To learn how to watch variable names and expressions, see the section How to Watch an Expression?

Execution

The execution starts from the first line of the Init function.

When the Init function is successfully completed, the indicator or strategy initialization dialog box appears. You must select market data to be used for testing of the indicator or strategy and set parameters. Note that you can set the Init function to be executed without your intervention. In this case the execution starts from the appearance of the initialization dialog box.

To skip the manual execution of the Init function

  • On the File menu, click Preferences.

  • The Preferences dialog box appears.

  • Click Debug "init" Method, and then click False.

  • Click OK.

After you set the parameters, the execution stops on the first line of the Preparefunction. When the Prepare function is successfully completed, the Update function is executed for each period of the data which you selected in the indicator initialization dialog.

Execution result

If no run-time errors occur, the output stream(s) produced by the indicator are shown in the Streams and Chart windows. The trading activity that is performed by the indicator or strategy is shown in the Statistics window. The Streams window also contains the source stream(s) with appropriate dates which can be used for analysis of the indicator result. Otherwise, the description of the errors will be shown in the Output window.

To view and use the source and output streams data in other applications, you can save them as a .csv file.

To save the source and output streams as a .csv file

  • On the File menu, click Save Streams Log.

  • In the File name box of the Save As dialog box, enter the name of the file.

  • Click Save.

You can also save a chart as a .png file.

To save the source and output streams as a .csv file:

  • On the File menu, click Save Chart.

  • In the File name box of the Save As dialog box, enter the name of the file.

  • Click Save.
