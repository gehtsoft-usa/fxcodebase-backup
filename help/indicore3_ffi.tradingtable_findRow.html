static public method indicore3_ffi.tradingtable_findRow

Brief

The function searches the trading table for a row with the specified column value.

Declaration
Lua
void * indicore3_ffi.tradingtable_findRow (void *table, const char *column, void *key)

Parameters
table

A pointer to the table in which the row is searched. The pointer must be obtained by using the indicore3_ffi.host_getTradingTable() function.
column

A name of the table column by which the row is searched. The following columns can be used:

Table

Columns

Accounts

AccountID, AccountName

Offers

OfferID, Instrument

Orders

OrderID, OfferID, TradeID, AccountID, RequestID, OCOBulkID

Trades

TradeID, AccountID, OfferID, OpenOrderID, OpenOrderReqID

Closed Trades

TradeID, AccountID, OfferID, OpenOrderID, OpenOrderReqID, CloseOrderID, CloseOrderReqID

Messages

MsgID
key

A pointer to the value to be searched in the specified column. Depending on the data type of the column, the pointer must be obtained by using the one of the following functions:

  • indicore3_ffi.parameterconstant_new_int().

  • indicore3_ffi.parameterconstant_new_double().

  • indicore3_ffi.parameterconstant_new_bool().

  • indicore3_ffi.parameterconstant_new_string().

A value returned by the indicore3_ffi.tradingtablerow_value() function can be also used as the parameter value.

Note that the key value must be deleted when it is no longer needed by using the indicore3_ffi.parameterconstant_delete() function.

Returns

The function returns a pointer to the row if the row is founded.
The function returns nil if the row that matches the searching criteria does not exist.

Details

The following functions are intended to work with the row:

Function

Description

indicore3_ffi.tradingtablerow_value()

The function returns a cell value of the row.

indicore3_ffi.tradingtablerow_refresh()

The function refreshes data in the row.

The row must be released when it is no longer needed by using the indicore3_ffi.core_object_release() function.

Note that if the table contains more than one row that matches the searching criteria, for example, there are number of trades that have been opened by one and the same order, the function returns only the first encountered row. In such cases, the indicore3_ffi.tradingtable_findAll() function can be used.

   ffi_offer = indicore3_ffi.parameterconstant_new_string(source:instrument());
   ffi_offers_row = indicore3_ffi.tradingtable_findRow(ffi_offers_table, "Instrument", ffi_offer);
   indicore3_ffi.core_object_release(ffi_offers_table);
   indicore3_ffi.parameterconstant_delete(ffi_offer);
   ffi_offerId = indicore3_ffi.tradingtablerow_value(ffi_offers_row, "OfferID");
   indicore3_ffi.core_object_release(ffi_offers_row);
