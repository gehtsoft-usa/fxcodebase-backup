Indicore 3 Lua Editor/Debugger Window

Brief

The section describes Indicore 3 Lua Editor/Debugger window.

Details

Indicore 3 Lua Editor/Debugger window consists of the project tree area (at the top left), the source code area (at the top right), and the information area (at the bottom). The areas are separated by splitters. You can drag the splitters to change the size of each area.

In the project tree area, you can view, add, and remove the indicators or/and strategies files to your project as well as the resource files for the project localization support. You can also use images, sounds and data files in your project. The following image file formats are supproted: .jpeg, .bmp, .png, .jpg, .ico. The .wav sound files and .txt, .csv, .xml data files are supported.

In the source code area, you can write, view, and correct the source code of the indicator or strategy. The line of the source code that is currently selected is highlighted. During the debugging process, the line that is currently executed is boxed.

The information area contains 12 windows which can be switched between using their tabs at the bottom of the information area.

The Output window shows messages and errors.

The Streams window shows the source and output streams of the indicator/strategy as a result of that indicator/strategy execution.

The Chart window shows the chart of the source price stream with the indicator or/and strategy applied as a result of that indicator or/and strategy execution.

The Statistic window shows the number of tick simulated during the indicator/strategy execution. In case of a strategy, the window shows the trading activity performed by the strategy and the results of that activity including the account information.

The Watches window shows the list of variables and expressions that you specify to watch their values during the execution.

The Stack window shows the functions of the indicator or strategy program which are currently executed.

The Offers, Accounts, Orders, Trades, Closed Trades, and Summary windows show the corresponding trading tables.
