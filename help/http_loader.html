table http_loader

Brief

Http loader

Details

Http loader can used to load simple pages using GET method over HTTP protocol.

POST or PUT methods and HTTPS protocol aren't supported.

For better http/https support please use http_lua extension.

Use core.makeHttpLoader() method to get an instance of the http_loader table.

Please find an example of loading data asynchronously below:

   function Init()
       ...
       indicator.parameters:addString("host", "The host to load the data", "", "www.myhost.com");
   end
 
   ...
   local timerId;
   local http_loader = nil;
   local S_INIT = 0;
   local S_LOADING = 1;
   local S_LOADED = 2;
   local S_FAILED = 3;
   local status = S_INIT;
   ...
   local output;
 
   function Update(period, mode)
       -- do not work we are loading data or data loading has been failed
       if status == S_LOADING or status == S_FAILED then
           return ;
       end
 
       -- if data is not loaded yet - start loading
       if status == S_INIT then
           http_loader = core.makeHttpLoader();
           status = S_LOADING;
           http_loader.load(instance.parameters.host, 80, "/mydata.html", true);
           core.host:execute("setStatus", "loading...");
           timerId = core.host:execute("setTimer", 100, 1);
           return ;
       end
 
       -- work using data
       ...
   end
 
   function AsyncOperationFinished(id, success, msg)
       if id == 100 then
           -- timer
           if status == S_LOADING then
               if not(http_loader:loading()) then
                   if http_loader:successful() then
                       local response = http_loader:response();
                       ... process response ...
                       status = S_LOADED;
                       core.host:execute("setStatus", "");
                       -- and force the indicator to be updated
                       -- to process new data
                       instance:updateFrom(source:first());
                   else
                       status = S_FAILED;
                       core.host:execute("setStatus", "http failed...");
                   end
                   core.host:execute("killTimer", timerId);
               end
           end
       end
   end
 
   -- when indicator is being released
   function ReleaseInstance()
       if status == S_LOADING then
           if http_loader:loading() then
               http_loader:cancel();
           end
           -- wait until http request is not finished (if any)
           while (http_loader:loading()) do
           end
       end
 
   end

Static Public Methods

cancel

Cancels currently executing load operation.

load

Loads an object using http interface

loading

Checks whether the last load asynchronous operation is being executed.

response

Returns the loaded object as a string.

successful

Checks whether the load operation has been successfully finished
