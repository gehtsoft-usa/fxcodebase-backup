public method host:execute("getSyncHistory", ...)

Brief

Loads the history of the specified instrument and keeps it synchronized with an indicator source.

Declaration
Lua
string host:execute ("getSyncHistory", instrument, barSize, bidOrAsk, barsAtLeft, commandIdSyncComplete, commandIdSyncStarted)

Parameters
instrument

The name of the instrument.
barSize

The size of the bar. See tick_stream:barSize for information about the period codes.

Use "t1" to load ticks.
bidOrAsk

The flag indicating whether bid (true) or ask (false) prices must be loaded.
barsAtLeft

The number of additional bars that should be loaded and kept before the first bar of the indicator source. See Details below for more information.
commandIdSyncComplete

The integer value to be passed to the AsyncOperationFinished function of the indicator when data is loaded or synchronization completed.
commandIdSyncStarted

The integer value to be passed to the AsyncOperationFinished function of the indicator when data is about to be loaded or synchronization is about to be started.

Details

The method is designed for obtaining the data of another instrument and/or another time frame for the time range the same as time range of the indicator source. The function simplifies this operation comparing with usage of getHistory/extendHistory calls.

The method return the stream which ends at the same time when the indicator source ends (and is subscribed to the updates if the indicator source is subscribed), and begins barsAtLeft bars before the indicator source begins. If the value of barsAtLeft is 0, the stream begins at the same bar as the indicator source.

Limitations

  1. The number of the barsAtLeft cannot exceed 300 and cannot be a negative value.

  2. When the stream exceeds the maximum number of prices (15000 for a bar stream and 5000 for a tick stream) only newest data is kept in the stream, any older data will be removed.

  3. The method can be used in the indicators only. The method is not supported for the strategies. When the indicator is applied at the chart, the stream will be synchronized with the price on the chart at which the indicator is applied. When the indicator is applied inside a strategy, the stream will be initially loaded by the requested size exactly as for host:execute("getHistory", ...) method.

  4. The index of the bar in the stream may differ from the index of the same bar in the main indicator source. Use core.findDate to find the bar in this stream.

Asynchronous Implementation

The data into the stream is loaded in background. That means that initially the method returns an empty stream.

When the initial loading or synchronization is started, the asyncOperationFinished method of the indicator will be called with commandIdSyncStarted command. The status of the stream after this call is void and it is not recommended to access the stream at this time.

When the initial loading or synchronization is finished, the asyncOperationFinished method of the indicator will be called with commandIdSyncFinished command.

   function Init()
       indicator:name("Show Yesterday Close");
       indicator:description("The indicator shows yesterday's close value on the chart");
       indicator:requiredSource(core.Tick);
       indicator:type(core.Indicator);
 
       indicator.parameters:addColor("clr", "Indicator Line Color", "", core.rgb(255, 0, 255));
   end
 
   local source;       -- indicator source data
   local first;        -- first available source data
   local days;         -- day source data
   local loading;      -- the loading day data flag
   local SYC;          -- yesterday close output
 
   local offset;
   local weekoffset;
 
   function Prepare()
       local name;
       name = profile:id() .. "(" .. instance.source:name() .. ")";
       instance:name(name);
       source = instance.source;
       first = source:first();
       loading = false;
       local host = core.host;
       offset = host:execute("getTradingDayOffset");
       weekoffset = host:execute("getTradingWeekOffset");
       SYC = instance:addStream("SYC", core.Line, name, "SYC", instance.parameters.clr, first);
 
       -- create a day source stream synchronized with the source, extra bars are not required
       days = host:execute("getSyncHistory", source:instrument(), "D1", source:isBid(), 0, 100, 101);
   end
 
   function Update(period, mode)
       if period < first then
           return ;
       end
 
       if loading then
           return ;
       end
 
       -- try to find the value in the days collection
       local yesterday;
       yesterday = getYesterday(source:date(period));
 
       -- find the day data
       local i;
       i = core.findDate(days, yesterday, false);
 
       if i >= 0 then
           SYC[period] = days.close[i];
       end
   end
 
   function AsyncOperationFinished(cookie, success, error)
       if cookie == 101 then
           loading = true;
       elseif cookie == 100 then
           assert(success, error);
           loading = false;
           instance:updateFrom(0);
       end
   end
 
   -- returns the beginning of the "yesterday" date for
   -- the specified data
 
   function getYesterday(date)
       local today, yesterday;
 
       -- get beginning of the today's candle and round it up to the second
       today = core.getcandle("D1", date, offset, weekoffset);
       today = math.floor(today * 86400 + 0.5) / 86400;
 
       -- get calendar yesterday
       yesterday = today - 1;
 
       local nontrading, nontradingstart;
       nontrading, nontradingstart = core.isnontrading(yesterday, offset);
 
       if nontrading then
           -- if the calendar yesterday date is non-trading (Friday 17:00 EST - Sunday 17:00 EST)
           -- nontradingstart is (Friday 17:00 EST). shift it for one day further.
           yesterday = nontradingstart - 1;
       end
 
       return yesterday;
    end
