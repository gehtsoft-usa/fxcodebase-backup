public method parameters:addDate

Brief

Adds a date or date/time parameter

Declaration
Lua
parameters:addDate (id, name, description, value)

Parameters
id

string: The unique identifier of the parameter.
name

string: The short name of the parameter.
description

string: The detailed description of the parameter.
value

double: The default value of the parameter.

The value should be a double number. That number means the number of days past midnight December 30, 1899 (also known as the OLE date/time format).

In case the value is greater than zero, the value is recognized as the date (date/time) to be shown by default.

In case the value is less than zero, the value is recognized as the number of the days to be subtracted from the current date (date/time) and that date will be shown by default.

In case the value is zero and the date parameter is nullable, the parameter will be nulled by default.

In case the value is zero and the date parameter is not nullable, the parameter will display the current date and time by default.

Details

The behavior of the method depends on the flag:

Flag

Behavior

core.FLAG_DATE

User can enter date only. The date is not nullable.

core.FLAG_DATE_OR_NULL

User can enter date only. The input field must contain an on/off selector. If the selector is on, the date can be modified and its value will be returned. If the selector is off, the date cannot be modified and zero value will be returned.

core.FLAG_DATETIME

User can enter date and time. The date is not nullable.

core.FLAG_DATETIME_OR_NULL

User can enter date and time. The input field must contain an on/off selector. If the selector is on, the date can be modified and its value will be returned. If the selector is off, the date cannot be modified and zero value will be returned.

Use the setFlag() method to set the flag of the parameter.
