table indicore3_ffi

Brief

The ffi functions.

Static Public Methods

barstream_getClose

The function returns the Close value of the specified period. The function is applicable only to a bar stream.

barstream_getHigh

The function returns the High value of the specified period. The function is applicable only to a bar stream.

barstream_getLow

The function returns the Low value of the specified period. The function is applicable only to a bar stream.

barstream_getOpen

The function returns the Open value of the specified period. The function is applicable only to a bar stream.

core_crosses

The function check whether the stream crosses the other stream in any direction at the specified period.

core_crosses2

The function check whether the stream crosses the specified level in any direction at the specified period.

core_crossesOver

The function checks whether one stream crosses over the other stream at the specified period.

core_crossesOver2

The function checks whether one stream crosses over the specified level at the specified period.

core_crossesOverOrTouch

The function checks whether the stream crosses over or touches the other stream at the specified position.

core_crossesOverOrTouch2

The function checks whether the stream crosses over or touches the specified level at the specified position.

The function checks whether the stream crosses under the other stream at the specified period.

core_crossesUnder2

core_crossesUnderOrTouch

The function checks whether the stream crosses under or touches the other stream at the specified period.

core_crossesUnderOrTouch2

The function checks whether the stream crosses under or touches the specified level at the specified period.

core_drawLine

The function draws the line in the output stream.

core_erase

The function sets no data to the specified range of periods in the output stream.

core_findDate

The function searches the specified stream for the specified date. The function returns the index of the period to which the specified date belongs.

core_getCandle

The function returns the start date of the period to which the specified date belongs.

core_isNonTrading

The function checks whether the specified date and time belongs to the regular non-trading hours (weekend).

core_math_avg

The function calculates the average value of the specified range of the stream values.

core_math_cfft

The function performs the fast complex fourier transform.

core_math_correlation

The function calculates the correlation coefficient between two streams in the specified ranges.

core_math_covariance

The function calculates the covariance between two streams in the specified ranges.

core_math_devsq

The function calculates the sum of squares of deviations of data points from their sample mean of the specified range of the stream values.

core_math_fft

The function performs the fast real fourier transform.

core_math_kurt

The function calculates the kurtosis of a distribution of the specified range of the stream values.

core_math_lreg

The function calculates the linear regression value of the specified range of the stream values.

core_math_lwma

The function calculates the linear-weighted average value of the range of the stream values.

core_math_meandev

The function calculates the mean deviation of the specified range of the stream values.

core_math_median_s

The function calculates the median value of the specified range of the stream values.

core_math_median_w

The function calculates the median value of the specified range of the stream values by using the the Wirth's Kth-minimum function.

core_math_regChannel

The function calculates the parameters of the regression channel.

core_math_skew

The function calculates the skewness of a distribution of the specified range of the stream values.

core_math_slope_lreg

The function calculates the linear regression slope of the specified range of the stream values.

core_math_stdev

The function calculates the standard deviation of the values of the range of the stream values.

core_math_sum

The function calculates the sum of the specified range of the stream values. The function calculates the sum of the stream values specified as a range.

core_object_release

The function releases the object.

core_parseCandle

The function returns the identifier of the specified period time frame.

core_touches

The function checks whether the stream touches the other stream at the specified period.

core_touches2

The function checks whether the stream touches the specified level at the specified period.
