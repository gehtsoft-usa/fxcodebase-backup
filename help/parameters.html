table parameters

Brief

The indicator or strategy parameters.

Details

Parameters in Init() function

The table parameters is available in the Init() function of the indicator or strategy as indicator.parameters (for indicators) or strategy.parameters (for strategy).

The table is used to create the parameter set of the indicator or strategy which will be shown to a user when the indicator (or strategy) is created.

The parameters are shown in the same order as they are created. The parameters can be grouped using addGroup() method. All parameters created after calling this method are included into the last created group. Groups are also shown in the order of creation.

Parameters of profile() of an indicator

The parameters of this instance of the indicator or strategy is available via instance_impl.parameters.

The parameters for other indicators can be obtained via profile:parameters() method.

Note that in addition to methods, you can get access to the parameters as to properties of the parameters table, i.e. parameters.N equals the parameter:getInteger("N"); for the integer parameter named N or equals the parameter:getString("N"); for the string parameter named N.
