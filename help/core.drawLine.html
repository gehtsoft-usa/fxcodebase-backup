static public method core.drawLine

Brief

Draws the line in the output stream.

Declaration
Lua
core.drawLine (output, range, value1, position1, value2, position2, color)

Parameters
output

The output stream of the indicator.
range

The range where to "draw" line in the output. The range can be created using core.range, core.rangeTo, or core.rangeFrom methods.

Both indexes of the range must be in output:first() <= index <= output:size() - 1.
value1

The value in the first point to calculate the line equation.
position1

(The index of) the position of the first point to calculate line equation.
value2

The value in the second point to calculate the line equation.
position2

(The index of) the position of the second point to calculate the line equation.

The position 2 must be bigger than position 1.
color

Optional. The color of the line. Use core.rgb() method to create a color or one of the colors returned by the core:colors() function. If the parameter is omitted, the color of the line is the color of the stream defined by the output parameter.

Details

Fills the range of the output by the values which represent a straight line drawn through the two specified points.

The line equation is calculated as:

price(index) := a * index + b;

where:

a := (value2 - value1) / (position2 - position1);
b := value1 - a * position1;

Then, each price in the output stream between range.from and range.to is filled by the price calculated using line equation.

Please note that this method is used to fill the indicator output stream. If you want to draw "free" line, without usage of the output stream, please use the core.host:execute("drawLine", ...) method.

   function DrawLine(output, source, bar1, bar2)
       core.drawLine(output, core.range(bar1, bar2), source[bar1], bar1, source[bar2], bar2);
   end
