public method interop_instance:invoke

Brief

Invokes a verb to the other instance.

Declaration
Lua
value, value?, value? interop_instance:invoke (name, ...)

Parameters
name

The name of the verb.

The verb may be:

  • A name of the field of the _G table of the callee.

    In this case no additional parameter must be specified. The method returns one value which is content of the field specified.

  • A name of the global function of the callee.

    In this case the additional parameter are the parameters for the function call. The method returns up to three values returned by the function.

Details

Note: Only simple types such as: nil, Boolean (true or false), number and string are marshalled. Tables, indicator core, user data, functions or chunks are not marshalled via interop.
