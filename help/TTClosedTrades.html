Closed Trades(table)

Brief

The section describes the "Closed Trades" table.

Details

The table includes information pertinent to positions that have been closed during the current trading day. The table shows such data as realized profit/loss, charged commission, cumulative interest, and other.

Name

Type

Description

TradeID

String

The unique number of the closed position. Corresponds to TradeID in the Trades table. The number is unique within the connection (Real or Demo).

You can search by this column.

AccountID

String

The unique number of the account the position is closed on. The number is unique within the connection (Real or Demo). In Order2Go, an account is always referred to by its Account ID.

You can search by this column.

AccountName

String

The unique name of the account the position is closed on. This is the name that is displayed to the FX Trading Station user. The name is unique within the connection (Real or Demo).

OfferID

String

The unique number of the instrument the position is opened in.

You can search by this column.

Instrument

String

The symbol indicating the instrument the position is open in. For example, EUR/USD, USD/JPY, GBP/USD.

Lot

Integer

Total closing amount.

Forex: The amount of the order expressed in the base currency of the instrument. For example, 20,000 for EUR/USD means that the amount of the order is 20,000 Euros, for USD/JPY - 20,000 US dollars, etc.

CFD: With CFD, the amount of the order is expressed in contracts. For example, 5000 for SILVER means that this order/position is for 5000 contracts of SILVER.

AmountK

Double

Total closing amount in thousands.

Forex: The amount of the order (in thousands) as specified by the FX Trading Station user. For example, 20 for EUR/USD means that the amount of the order is 20,000 Euros, for USD/JPY - 20,000 US dollars, etc.

CFD: The number of contracts (in thousands). For example, the position for 5000 contracts will display 5 in this field.

BS

String

The trade operation the position is closed by. Possible values:

B

Buy.

S

Sell.

Open

Double

The price the position was opened at.

Close

Double

The price the position was closed at.

PL

Double

The profit/loss (on 1 contract) of the position expressed in pips.

GrossPL

Double

The profit/loss of the position in the account currency.

Com

Double

The commission, i.e. the amount of funds that is subtracted from the account for various reasons which are defined individually for each particular account by the terms and conditions of the trading agreement. The commission is expressed in the account currency.

Int

Double

The interest, i.e. the cumulative amount of funds that is added to/subtracted from the account for holding the position overnight. The interest is expressed in the account currency.

OpenTime

DateTime

The date and time when the position was opened. The date and time are in the EST/EDT time.

CloseTime

DateTime

The date and time when the position was closed. The date and time are in the EST/EDT time.

Kind

String

The type of the account the position was opened on. Possible values:

32

Trading account.

36

Managed account.

38

Controlled account.

OpenOrderID

String

The unique number of the order the position was opened by.

You can search by this column.

OpenOrderReqID

String

The unique identifier of the order request the position was opened by. (see RequestID column of the orders table).

You can search by this column.

CloseOrderID

String

The unique number of the order the position was closed by.

You can search by this column.

CloseOrderReqID

String

The unique identifier of the order request the position was closed by. (see RequestID column of the orders table).

You can search by this column.

OQTXT

String

The text comment added to the order the position was opened by.

CQTXT

String

The text comment added to the order the position was closed by.

TradeIDOrigin

String

This column is filled in case the trade was created as a result of partial closing of another trade and contains the trade id of this partially closed trade.

TradeIDRemain

String

This column is filled in case the trade was closed partially and contains the identifier of the trade which was created for the remaining amount.
