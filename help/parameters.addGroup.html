public method parameters:addGroup

Brief

Starts the group of the parameters.

Declaration
Lua
parameters:addGroup (name)

Parameters
name

string: The name of the parameter group.

Group names "Calculation" and "Style" will be translated to all supported languages automatically, when the indicator parameter dialog is shown.

Details

All parameters created after call of this method (and before the next call of this method) will belong to the group.

Group is used to display the parameters only.
