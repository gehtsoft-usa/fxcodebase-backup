public method instance_impl:addInternalStream

Brief

The method adds an output stream for the indicator internal purposes.

Declaration
Lua
output_stream_impl instance_impl:addInternalStream (firstPeriod, extent)

Parameters
firstPeriod

The first period where data in the stream is available. For example, if you implement the Moving Average(N) indicator (formula is: MVA(i) := (PRICE[i - N + 1] + PRICE[i - N + 2] + ... + PRICE[i]) / N), you cannot provide data for the first N periods. So, you must specify the number that equals your source first period plus N.
extent

Optional. The parameter specifies the difference between the source size and the output size. The positive number means that the output is longer than the source, the negative number means that the output is shorter than the source. The default value is 0.

Returns

The method returns an instance of the output_stream_impl table.

Details

The stream behaves exactly as a regular output stream but it is not listed in the output steams of the indicator, so it is not drawn as the indicator output. However, you can include the internal streams into indicator output groups.

   function Init()
       ...
       indicator:requiredSource(core.Tick);
       ...
       indicator.parameters:addInteger("N", "Number of bars to calculate", "", 7);
       ...
       indicator.parameters:addColor("clr", "Line color", "", core.rgb(255, 0, 0));
       ...
   end
 
   local n;
   local source;
   local first;
   local output;
   local first_i;
   local internal;
   local first;
 
   function Prepare()
       ...
       n = instance.parameters.N;
       source = instance.source;
       first_i = source:first() + n - 1;
       first = first_i + n - 1;
       ...
       local name;
       name = profile:id() .. "(" .. source:name() .. "," .. n .. ")";
       ...
       internal = instance:addInternalStream(first_i, 0);
       output = instance:addStream("out", core.Line, name .. ".out", "out", instance.parameters.color, first)
       ...
   end
 
   function Update(period, mode)
       if period >= first_i then
           -- calculate avg(source)
           internal[period] = mathex.avg(source, period - n + 1, period);
       end
       if period >= first then
           -- calculate avg(avg(source))
           output[period] = mathex.avg(internal, period - n + 1, period);
       end
   end
