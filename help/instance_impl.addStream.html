public method instance_impl:addStream

Brief

The method adds an output stream to the indicator.

Declaration
Lua
output_stream_impl instance_impl:addStream (id, type, fullName, label, color, firstPeriod, extent)

Parameters
id

The stream identifier. The identifier must contain only English letters or digits and must be unique within the instance of the indicator.
type

The type of the stream graphical representation. The possible values are: core.Dot, core.Line, and core.Bar.
fullName

The full name of the stream. The recommended style is: Indicator identifier(Source Name, Parameter 1, ... Parameter N).Label If the indicator has only one stream, .Label can be omitted.
label

The short name of the stream. If the indicator has only one stream, the label must be equal to the indicator identifier.
color

The color of the stream. The color can be created by using the core.rgb function.
firstPeriod

The first period where data in the stream is available. For example, if you implement the Moving Average(N) indicator (formula is: MVA(i) := (PRICE[i - N + 1] + PRICE[i - N + 2] + ... + PRICE[i]) / N), you cannot provide data for the first N periods. So, you must specify the number that equals your source first period plus N.
extent

Optional. The parameter specifies the difference between the size of the source stream and the size of the output stream. The positive number means that the output is longer than the source. The negative number means that the output is shorter than the source. The default value is 0.

Returns

The method returns an instance of the output_stream_impl table.

   function Init()
       ...
       indicator:requiredSource(core.Tick);
       ...
       indicator.parameters:addInteger("N", "Number of bars to calculate", "", 7);
       ...
       indicator.parameters:addColor("clr", "Line color", "", core.rgb(255, 0, 0));
       ...
   end
 
   local n;
   local source;
   local output;
   local first;
 
   function Prepare()
       ...
       n = instance.parameters.N;
       source = instance.source;
       first = source:first() + n - 1;
       ...
       local name;
       name = profile:id() .. "(" .. source:name() .. "," .. n .. ")";
       ...
       output = instance:addStream("out", core.Line, name .. ".out", "out", instance.parameters.color, first)
       ...
   end
 
   function Update(period, mode)
       if period >= first then
           output[period] = mathex.avg(source, period - n + 1, period);
       end
   end
