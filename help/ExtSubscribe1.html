ExtSubscribe1 function of helper.lua

Brief

The function is designed to subscribe for bar histories in the strategies

Details

Declaration

ExtSubscribe1(id, instrument, period, count, bid, kind)

Brief The function subscribes a strategy for a bar history. In order to use this function please follow the instruction in the Applying the strategy on candle data using the helper article.

Requested count of bars of this history is initially loaded. After that, at every tick the helper.lua checks whether another bar of the requested collection is recently closed (in other words it checks whether the tick is the first tick after a bar is closed. In case it is, the helper.lua calls ExtUpdate function of the strategy.

In case both tick and bar data is required, you must subscribe for ticks using the same function. In this case no data will be loaded, the instance.bid or instance.ask collections are returned.

Parameters

Name

Description

id

The integer number which will be used as an unique identifier of your subscription. This identifier must also be different from the identifies of the times and commands.

instrument

The name of the instrument (e.g. "EUR/USD") or nil to use the instrument on which the strategy is applied.

period

The code of the period (length of the time frame). See the tick_stream:barSize() method for more details about the period codes.

count

The quantity of bars which will be initially loaded by the system. The value must be positive.

bid

The boolean flag true will request for bid prices history and the flag false for ask price history.

kind

A string parameter which defines which prices must be collected. Can have one of the following values:

"bar"

The method returns an instance of the bar_stream table which will contain OHLC bars of the requested instrument during the requested time frame.

"open"

The method returns an instance of the tick_stream table which will contain open prices of bars of the requested instrument during the requested time frame.

"high"

The method returns an instance of the tick_stream table which will contain high prices of bars of the requested instrument during the requested time frame.

"low"

The method returns an instance of the tick_stream table which will contain low prices of bars of the requested instrument during the requested time frame.

"close"

The method returns an instance of the tick_stream table which will contain the close prices of bars of the requested instrument during the requested time frame.

The function returns a price stream. The data are not available immediately, stream is empty and data is being loaded.
