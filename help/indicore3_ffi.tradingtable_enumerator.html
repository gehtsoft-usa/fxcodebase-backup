static public method indicore3_ffi.tradingtable_enumerator

Brief

The function creates an enumerator for the specified trading table.

Declaration
Lua
void * indicore3_ffi.tradingtable_enumerator (void *table)

Parameters
table

A pointer to the table for which the enumerator is created. The pointer must be obtained by using the indicore3_ffi.host_getTradingTable() function.

Returns

The function returns a pointer to the newly created enumerator.

Details

The enumerator is used to enumerate rows in a trading table.

The following functions are intended to work with the enumerator:

Function

Description

indicore3_ffi.tradingtableenumerator_next()

The function returns the next row of the table.

indicore3_ffi.tradingtableenumerator_reset()

The function resets the enumerator.

The enumerator must be released when it is no longer needed by using the indicore3_ffi.core_object_release() function.

The indicore3_ffi.tradingtable_findAll() function also returns a enumerator for the trading table but the content of that table is already filtered by the specified criteria.
