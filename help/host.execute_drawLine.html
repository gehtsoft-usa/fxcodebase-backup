public method host:execute("drawLine", ...)

Brief

Creates or replaces a line.

Declaration
Lua
string host:execute ("drawLine", id, fromDate, fromLevel, toDate, toLevel, color, style?, width?, tooltip?)

Parameters
id

The line identifier (an integer number). The identifier must be unique for all the lines drawn by the same instance of the indicator. If line with the specified id exists, it will be replaced.
fromDate

The date and time from which line must be drawn.

If fromDate is equal to -2 then the line will be drawn from the right border of the chart and length of the line expressed in points (1pt is 1/72 of inch) is passed in the toDate parameter.
fromLevel

The price level from which line must be drawn.
toDate

The date and time to which line must be drawn.
toLevel

The price level to which line must be drawn.
color

Integer. The color of the line. You can either create your own color using core.rgb(), choose one of the color returned by core.colors(), or specify one of the following constants: core.COLOR_LABEL, core.COLOR_LINE, core.COLOR_UPCANDLE, core.COLOR_DOWNCANDLE, core.COLOR_CUSTOMLEVEL, core.COLOR_BACKGROUND to use the Marketscope's default colors.
style

[optional]The style of the line. The default style is a solid line.

core.LINE_SOLID

A solid line

core.LINE_DASH

A dash line

core.LINE_DOT

A dot line

core.LINE_DASHDOT

A dash-dot line
width

[optional]Width of the line in pixels. The default width is 1 pixel.
toolip

[optional]The tooltip to show on the line.

Details

Note: This function is optional and may be not supported by the host application.

Comparing to the core.drawLine() this function does not use the output_stream, but just sends to the host a command to draw a line over the chart canvas. Therefore the line is drawn much faster and you are able to drawn as much line trough the same bar as you need. However, the data of the line is not available back. All you can is to remove the line.

To remove the line use the host:execute("removeLine"); method.

The method can be used in indicators only.
