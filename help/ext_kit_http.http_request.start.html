public method http_request:start

Brief

Starts the data loading

Declaration
Lua
boolean http_request:start (url, method?, data?)

Parameters
url

String. The URL of the resource to be loaded. The URL must include the scheme name (http or https), the host name, optionally the port and the path to the resource to be loaded.

The example of the URL is:

http://www.myhost.com:8080/myData

where: http is scheme name
www.myhost.com is the host address
8080 is the post
/myData is the path to the resource.

The port can be omitted in case the default port must be used (80 for http and 443 for https).

The parameters (if any exists) are usually a part of the path, for example if the resource myData in the example above required two parameters, the URL would look like this:

http://www.myhost.com:8080/myData?param1=value1&param2=value2
method

String, optional. The http method. The most servers support "GET", "POST" and "PUT".

If value is not specified, the "GET" method is used.
data

String, optional. The data to upload to the server as a part of the request.

The parameter is generally used together with "POST" and "PUT" methods.

If the parameter is not specified, no additional data is sent to the server.

Details

Please note that method only starts the loading of the data and then returns immediately. You have to use:

1) http_request:loading() method to check whether the operation has been finished;

2) then http_request:success() method to check whether the server communication has been performed successfully;

3) and, finally http_request:httpStatus() method to check whether the server performed the request successfully.

To avoid handing of the host application when a long-running request is executed, please use timer of alternative asynchronous operation interface for watching for the operation result. Please see an example in the http_request:success() method documentation for details how to watch for the operation result properly.
