public method core.indicators:create

Brief

Creates an instance of the indicator.

Declaration
Lua
instance core.indicators:create (id, source, parameters...)

Parameters
id

The indicator identifier.

The indicator identifier is capitalized file name of the indicator without extension. For example, identifier of the indicator stored in file MyIndi.lua is "MYINDI".
source

The stream of prices or output stream of other (not this) indicator. You must pass either an instance of the bar_stream table in case the indicator requires the core.Bar source (see the profile:requiredSource() method) or an instance of the tick_stream table in the other case.
parameters

One or more values to be assigned as parameters. The first value will be assigned to the first parameter, the second value - to the second parameter, etc. Up to five parameters can be specified.

If you need to create an instance of the indicator with more than five parameters, please use profile:createInstance() method.

If you don't specify the parameter(s) for an indicator which has parameters, the default value of the parameters will be used.

Returns

The instance of the instance table.

Please, note that all output streams of the indicator instance aren't synchronized or filled until you call instance:update() method.
