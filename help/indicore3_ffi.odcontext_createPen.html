static public method indicore3_ffi.odcontext_createPen

Brief

The function creates a GDI pen.

Declaration
Lua
void indicore3_ffi.odcontext_createPen (void *context, int objid, int style, int width, int color)

Parameters
context

The context object.
objid

The identifier of the pen object. The indicator has 64 slots for GDI objects. The number of the first object is 0. The number of the last object is 63. If the specified identifier is already used by the previously created object, the already existed object is deleted.
style

The style of the pen. The possible values are:

context.SOLID

A solid line.

context.DOT

A dotted line.

context.DASH

A dashed line.

context.DASHDOT

A line or alternating dashes and dots.

context.DASHDOTDOT

A line or alternating dashes, dot, dot pattern.
width

The width of the line in pixels.
color

The color of the line. The core.rgb() function can be used to create a color. See also the core.colors() function.
