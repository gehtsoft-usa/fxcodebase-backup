Offers(table)

Brief

The section describes the "Offers" table.

Details

The table contains information about trading instruments, current prices as well as high/low trading day prices.

Name

Type

Description

OfferID

String

The unique number of the instrument.

You can search by this column.

Instrument

String

The symbol indicating the instrument. For example, EUR/USD, USD/JPY, GBP/USD.

You can search by this column.

InstrumentType

Integer

The type of the instrument. Possible values:

1

Forex.

2

Indices.

3

Commodity.

4

Treasury.

5

Bullion.

6

Shares.

7

FXIndex.

Bid

Double

The current market price the instrument can be sold at.

Ask

Double

The current market price the instrument can be bought at.

Hi

Double

The highest Ask price (buy price) of the instrument for the current trading day. The trading days are from 17:00 to 17:00 EST.

Low

Double

The lowest Bid price (sell price) of the instrument for the current trading day. The trading days are from 17:00 to 17:00 EST.

IntrS

Double

The interest that is added to/subtracted from the account for holding overnight a 1 lot sell position opened in this instrument. The interest is expressed in the account currency.

IntrB

Double

The interest that is added to/subtracted from the account for holding overnight a 1 lot buy position opened in this instrument. The interest is expressed in the account currency.

ContractCurrency

String

The base currency of the instrument (EUR - in EUR/USD, USD - in USD/JPY, GBP - in GBP/USD, etc).

ContractSize

Integer

The legacy lot size in the base currency of the instrument which is supported for the backward compatibility. Always equals 1.

Digits

Integer

The number of digits after the decimal point to which the price of the instrument is rounded in calculations. For example, it is 5 for EUR/USD and GBP/USD, and 3 for USD/JPY.

DefaultSortOrder

Integer

The sequence number of the instrument in the list of instruments displayed to the FX Trading Station user.

PipCost

Double

The cost of one pip per lot. The cost is expressed in the account currency. PipCost is used for calculation of the P/L value in account currency.

See also Account Mathematics article for details.

MMR

Double

Minimum Margin Requirement.

The amount of funds which must be allocated for trading 1 lot in this instrument; depends on leverage. The lot size is defined by BaseUnitSize (use getTradingProperties to get the base unit size for the specified account/instrument).

The minimum margin requirement is expressed in the account currency.

For example, for $100,000 lot size and 1:100 leverage the minimum margin requirement is $1,000.

This is the minimal margin (of Entry, Maintenance and Liquidation margin requirements) for the instrument among all the user's accounts. To get certain margin requirement for certain account, please use host:execute("getTradingProperty", ...) method.

See also Account Mathematics article for details.

Time

DateTime

The date and time of the last update of the instrument. The date and time are in the EST/EDT time.

BidChangeDirection

Integer

The direction the Bid price (sell price) of the instrument is changing in. Possible values:

0

Not changing.

1

Going up.

-1

Going down.

AskChangeDirection

Integer

The direction the Ask price (buy price) of the instrument is changing in. Possible values:

0

Not changing.

1

Going up.

-1

Going down.

HiChangeDirection

Integer

The direction the highest Ask price (buy price) of the instrument is changing in. Possible values:

0

Not changing.

1

Going up.

-1

Going down.

LowChangeDirection

Integer

The direction the lowest Bid price (sell price) of the instrument is changing in. Possible values:

0

Not changing.

1

Going up.

-1

Going down.

QuoteID

String

The unique number of the pair of prices (Bid and Ask) the instrument can be traded at.

BidID

String

The unique number of the Bid price.

AskID

String

The unique number of the Ask price.

BidExpireDate

DateTime

The date and time up to which the Bid price is available for trading. The date and time are in the EST/EDT time.

AskExpireDate

DateTime

The date and time up to which the Ask price is available for trading. The date and time are in the EST/EDT time.

BidTradable

String

Defines whether the Bid price of the instrument is available for trading. Possible values:

T

The Bid price is available for trading.

I

The Bid price is view only.

N

the Bid price is not available for trading.

AskTradable

String

Defines whether the Ask price of the instrument is available for trading. Possible values:

T

The Ask price is available for trading.

I

The Ask price is view only.

N

the Ask price is not available for trading.

PointSize

Double

The size of a pip. PointSize is a decimal number. For example, it is 0.0001 for EUR/USD, GBP/USD, and USD/CHF, and 0.01 for USD/JPY. Please note that in order to define the minimum possible change of the price, it is necessary to use the Digits column of the "Offers" table.

ExpireDate

DateTime

The date and time until which the order is valid. Used for GTD orders only. For other orders this column will contain 0. The date and time are in the EST/EDT time.
