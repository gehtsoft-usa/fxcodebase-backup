Brief

Regular Expression Extension Kit.

Static Public Methods

compile

Compiles the regular expression

ismatch

Briefly checks whether the expression matches the text.

Public Constant Properties

ANCHORED

Compile Option: Makes a pattern "anchored".

CASELESS

Compile Option: Makes the expression is a case insensitive.

DOLLAR_ENDONLY

Compile Option: Forces "$" patten to match only the end of the string.

DOTALL

Compile Option: Forces '.' pattern to match new lines.

EXTENDED

Compile Option: Ignores whitespace data characters in the pattern.

FIRSTLINE

Compile Option: Forces pattern matching at the line start.

MULTILINE

Compile Option: States that the expression must match multi-line strings.

NEWLINE_*

Compile Option: Override the default end-of-line characters (NEWLINE_CR, NEWLINE_LF, NEWLINE_CRLF, NEWLINE_ANY).

UNGREEDY

Compile Option: Inverts greediness of the quantifiers.

UTF8

Compile Option: Both, expression and line to match is in UTF-8 encoding.
