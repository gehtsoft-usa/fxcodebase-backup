Draw(stage, context) function

If the indicator has declared itself as an owner-drawn indicator, the Draw() function must be defined in the indicator.

The Draw() function of the indicator is called every time when the chart, that contains the owner-drawn indicator, is being repainted.

If the indicator is an oscillator is has declared itself as an owner-drawn for the main price area, the Draw() function will be also called when a main chart area is drawn. Please note that the context passed for main price area stages is not the same as the context passed for the indicator area, so you have to create all required objects for this context as well.

The function has two parameters:

Parameter

Description

stage

The painting stage. Actually, the function is called for each repaint of the chart for three times for each owner drawn area:

stage==0

The function is called right after the chart grid is drawn.

stage==1

The function is called after the price and all indicators which are applied before this indicator is painted.

stage==2

The function is called after all visible streams and objects of the indicator are painted.

stage==100

The function is called right after the chart grid in main chart area is drawn.

stage==101

The function is called after the price in main chart area is painted.

stage==102

The function is called after all visible streams and objects of the indicator are painted in main chart area.

context

The painting context. The parameter is an instance of context table and must be used to get all information about the chart and to draw objects on the chart.

The function works differently from the objects created via host:execute("drawLine") function. It is called every time when chart is painted and the host application does not keep or track any information about the objects created during the draw. Also, all context methods works in terms of pixels, not in terms of date/time and price, so every time when the chart is scrolled, zoomed, or the size of the chart window is changed, the position and size of the objects are changed accordingly.

The Draw() function is a very powerful tool to create almost any presentation the indicator may need, but, because it performs a lot of work and is called every time when the chart is painted (and it is very often), the developer must be very vigilant about the performance of this function. Please read the Performance of Draw() function article carefully.

Below there is an example of owner-drawn indicator implementing a Draw() function. This indicator makes a semi-transparent fill of the area below the prices. The top of the area is defined by the close prices of the chart.

function Init()
    indicator:name("Draw the close price path");
    indicator:description("");
    indicator:requiredSource(core.Bar);
    indicator:type(core.Indicator);
 
    indicator.parameters:addGroup("Style");
    indicator.parameters:addColor("color", "Fill Color", "", core.rgb(0, 255, 255));
    indicator.parameters:addInteger("transparency", "Fill Transparency", "0 - opaque, 100 - transparent", 75, 0, 100);
end
 
local first = 0;
local source = nil;
local output;
local color;
local transparency;
 
-- initializes the instance of the indicator
function Prepare(onlyName)
    source = instance.source;
    first = source:first();
    local name = profile:id() .. "(" .. source:name() .. ")";
    instance:name(name);
 
    if onlyName then
        return ;
    end
 
    output = instance:addStream("output", core.Line, name, "output", instance.parameters.color, 0);
    output:setVisible(false);
    instance:ownerDrawn(true);
 
    color = instance.parameters.color;
    transparency = instance.parameters.transparency;
    if transparency == 100 then
        transparency = 255;
    elseif transparency == 0 then
        transparency = 0;
    else
        transparency = math.floor(255 * (transparency / 100.0) + 0.5);
    end
end
 
function Update(period)
    output[period] = source.close[period];
end
 
local init = false;
 
function Draw(stage, context)
    if stage == 0 then
        if not init then
            context:createSolidBrush(1, color);
            init = true;
        end
 
        local points = context:createPoints();
        local first = true;
        local last = nil;
        local m, p;
 
        context:startEnumeration();
        while true do
            index, x, x1, x2, c1, c2 = context:nextBar();
            if index == nil then
                break;
            end
            if first then
                if index == 0 then
                    m, p = context:pointOfPrice(source.open[index]);
                    points:add(context:left(), p);
                else
                    m, p = context:pointOfPrice(source.open[index - 1]);
                    points:add(context:left(), p);
                end
                first = false;
            end
            last = index;
            m, p = context:pointOfPrice(output[index]);
            points:add(c2, p);
        end
 
        if (last ~= nil) then
            m, p = context:pointOfPrice(output[last]);
            points:add(context:right(), p);
            points:add(context:right(), context:bottom());
            points:add(context:left(), context:bottom());
 
            context:drawPolygon(-1, 1, points, transparency);
        end
    end
end
