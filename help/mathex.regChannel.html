static public method mathex.regChannel

Brief

Calculate the regression channel parameters.

Declaration
Lua
a, b, dev, raff mathex.regChannel (stream, from, to)

Parameters
stream

The stream of ticks.
from

The index of the period to calculate the value from.
to

The index of the period to calculate the value to.

Returns

The method returns four values:

a and b

The parameters for the main regression line equation: price := a * x + b where x := (index - from + 1), so the x for the period from is 1.

dev

The distance for upper and lower lines of the standard deviation channel with number of deviations equal to 1.

raff

The distance for upper and lower lines of the raff channel.

Details

Please note that all the periods inside the range specified must conform the following rule: stream:first() <= index <= stream:size() - 1

   local source;           -- must be a tick source!
   local output;           -- one of output channels
   local a, b, dev, raff;
   local channel = false;
   local calcfor = nil;
   ...
   function Update(period, mode)
       -- detect when more data is loaded in history
       if calcfor ~= nil and source:serial(source:first()) ~= calcfor then
           channel = false;
       end
       -- if there is enough data - calculate the channel parameters
       if not(channel) and source:first() + 100 - 1 < source:size() then
           a, b, dev, raff = mathex.regChannel(source, source:first(), source:first() + 100 - 1);
           calcfor = source:serial(source:first());
           channel = true;
       end
 
       if channel then
           -- calculate the index of this period inside the channel
           -- if channel is build from the period other from first
           -- use the index of the first period of the channel
           -- instead of source:first()
           local index = period - source:first() + 1;
           local central_line = a * index + b;
           local dev_up = central_line + dev;
           local dev_dn = central_line - dev;
           local raff_up = central_line + raff;
           local raff_dn = central_line - raff;
 
       end
   end
