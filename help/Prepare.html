Prepare(nameOnly)

Brief

The indicator instance initialization

Details

The function is called every time when the user applies the indicator to the data. At this moment, a copy of the indicator is created. This copy is called the indicator instance. At one moment, there can be as many indicator instances as many times the indicator is applied to user's data.

In this function you must:

  • Prepare all common data for further calculation of the indicator values.

  • Create all output streams of indicator.

When the function is being executed, there is a global variable called instance. You must use this variable to describe all necessary information and access to the source and parameters data.
Parameter nameOnly indicates whether this function was called just for creating instance's name.

Example: Prepare function example Hide

   -- Process a new instance creation.
   local first = 0;    -- the number of the first period at which the data can be processed
   local n = 0;        -- the number of the periods in the indicator source
   local source = nil; -- the source of the indicator instance for further usage
   local out = nil;    -- the instance of the output stream for further usage
   function Prepare(nameOnly)
       -- Get the source of this indicator instance and keep in the global variable
       -- However, you can access this information (as well as parameters) using the
       -- instance table, but access to the global variables is much faster
       source = instance.source;
       -- Get the number of the periods to calculate chosen by the user
       n = instance.parameters.N;
       -- Calculate the number of the period at which the first value can be processed, and keep it.
       -- For MVA the first period is equal to the value of the N parameter.
       first = n + source:first() - 1;
 
       -- Create the full name of the stream.
       local name;
       name = "MVA(" .. source:name() .. "," .. n .. ")";
       if (not (nameOnly)) then
           -- Create the line with the full name created above and the label "MVA", with the color chosen
           -- by a user and which is starting at the first period calculated above.
           out = instance:addStream("MVA", core.Line, name, "MVA", instance.parameters.C, first);
       end
   end

Important:

An indicator instance is always created in a new context. The Init() function is not called for an instance, so there is no way to pass data from the Init() function to the Prepare() function.
