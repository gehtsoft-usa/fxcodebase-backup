View Indicators

Brief

The section describes creation and usage of view indicators.

Details

A view indicator is an special case of the indicator which isn't applied to any source, but produces the source itself instead.

The view indicator is useful to show 3rd party data on the chart or to create a presentation of the data which does not fit into the standard time axis, for example such as Point & Figure chart.

In a host application, a view indicator is not added to an existing chart. It can be used to create for a new chart and its output is used to display prices on this new chart.

Because the indicator isn't applied to any source:

  • The instance.source value is not specified;

  • The indicator shall define its own time line and all its outputs will be synchronized with this time instead of time line of the source.

  • The view indicator cannot use the following host:execute methods:
    host:execute("getBidPrice")
    host:execute("getAskPrice")
    host:execute("getSyncHistory")
    host:execute("attachOutputToChart")
    host:execute("attachTextToChart")

  • The view indicator can takes it data from any source (3rd party providers, files) or can access to Marketscope data via host:execute("getHistory") and can subscribe itself to updates via host:execute("subscribeTradeEvents").

    It can also use timers to activate itself.

  • The Update() function of the indicator is never called. All handling of the data must be performed in AsyncOperationFinished() of the indicator instead.
