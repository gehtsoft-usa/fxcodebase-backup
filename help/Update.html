Update(period, mode)

Brief

The indicator calculation

Details

Update is the most important function in the indicator. The update function is called for every period of the source to calculate the indicator value for the specified period. In this function, you must do all calculations and fill the output streams with appropriate values. During the moment of this function execution, all output and internal streams has the same size as the source. The period(s) which have not been calculated yet are filled with nil values (that means no data is available).

There are a number of the cases when the Update function can be called:

  • When the indicator is initially applied on the source, the Update function will be sequentially called for all periods, starting at 0 and finishing at source:size() - 1.

  • When a new period of the source appears (for example when a new bar is started) or the last period of the source is changed (for example high, low or close values of the bar is changed), the Update function is called for the last source:size() - 1 period.

  • When a number of periods disappear at the beginning of the source (for example, Marketscope application removes the first period(s) if the size of the data is greater than 1000 periods), the corresponding periods of the output and internal streams will be also removed.

  • When a large number of periods appears at the beginning of the source (for example, when the user scrolls the history into past in the Marketscope application), the Update function will be executed for all periods as for the initial creation.

In common, during the moment of function execution, you must suppose that the period specified in the parameters is the last available period of the source.

Please note that the period index for the same date and time can be changed, when data appears or disappears at the beginning of the source stream. Therefore, you must not use arrays and tables to keep intermediate data for the periods. Use the internal streams instead.

The second parameter of the function (mode) indicates how the indicator is calculated. The parameter value is core.UpdateAll for the first call of the Update. This is passed when indicator is initially calculated or recalculated completely because new data appears in beginning of the source. The parameter value is core.UpdateLast in other cases.

When this function is being executed, there is a global variable called instance which contains exactly the same content as at the moment of execution of the Prepare() function.

   -- Calculate the value of the indicator for one period.
   function Update(period, mode)
       -- Check whether the period is after the first period where we can calculate data.
       if (period >= first) then
           -- Calculate the value and set it to the output.
           out[period] = core.avg(source, core.rangeTo(period, n));
       end
   end
